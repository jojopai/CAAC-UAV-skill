# 无人机适航取证路线图与行动计划

依据：AP-21-11R2、AP-21-18、AP-21-31R3（均自 2026-07-01 生效）
终态目标：**型号合格证（TC）在手 + 设计机构许可证（DOA）在手 + 生产机构许可证（POA）在手**，从而使我们的无人机可以合法地按批准设计批量生产、取得适航证、投入运行。

> **重要补充（后续检索所得）**：本路线图的第一件事应当先是"**定类别**"。无人机还适用专用程序 AP-21-AA-2022-71 与分级分类指南 AC-21-AA-2022-40，类别（限用类 / 正常类 / 运输类）决定申请受理单位、审定基础、适航证类型乃至是否需要做本路线图的全套工作。判定方法见 [04_无人机专用法规与适航标准要点.md](04_无人机专用法规与适航标准要点.md)。若最大起飞重量不超过 25 kg，则无需适航许可，本路线图整体不适用。

## 一、先定五个决策点（不解决这些，后面所有工作都是空的）

| 编号 | 决策点 | 为什么必须先定 | 影响 |
|---|---|---|---|
| **D1** | 我们的无人机按什么类别申请？是否属于**限用类民用无人驾驶航空器** | 决定能否用 AP-21-11R2 **附录 H** 简化程序 | 免功能可靠性试飞、可不做局方审定飞行试验、POA 可只选必要准则 —— 工作量与周期差异巨大 |
| **D2** | **最大起飞重量（MTOW）** 是否超过 1360 kg | AP-21-18 第 3.1.1 条的一类/二类分界 | 超过 1360 kg 须**第一类 DOA**，设计保证系统须含完整安全管理要素；≤1360 kg 可走第二类 DOA |
| **D3** | **运行场景**如何界定（人口密集程度、隔离飞行、超视距、载人/载货、高度、空域） | AP-21-11R2 第 3.7.1(3)：局方**按运行场景对应的运行风险**裁剪审定基础 | 运行场景写得太"野"→ 条款多且严；写得太窄→ 后续扩展需改 TCDS |
| **D4** | 是否已有/是否要立即递交**型号合格证申请** | AP-21-11R2 附则：2026-07-01 前已申请未获批的，2027-07-01 前可先拿 TC、DOA 最晚 2027-07-01 | 决定我们是"TC 与 DOA 并行"还是"先 DOA 后 TC"，直接影响 2027-07-01 前的窗口利用 |
| **D5** | **设计、生产是否同一法人**；遥控台（站）是否独立取证 | AP-21-31R3 第 3.1.3：同一法人不需权益转让协议但须书面接口程序 | 决定是否需要与第三方签权益转让协议、是否要为遥控台（站）单独准备取证对象 |

## 二、三条工作线及其依赖关系

```
 并行推进 ─────────────────────────────────────────────────────────────►

  A 线：设计机构资格（AP-21-18）
      建体系文件 → 任命责任经理/适航经理/(安全经理)/独立监督负责人
      → 指定 CVE → 编 DOA 符合性检查单 → 递交 DOA 申请
      → 首次审查会 → 文件+记录审查+人员面谈 → 末次审查会 → 颁证
                                    │
                                    │  DOA 是颁 TC 的前置条件
                                    ▼
  B 线：产品型号（AP-21-11）
      递交 TC 申请（含运行场景说明）→ 受理缴费用 → 一般/技术熟悉会
      → 确定审定基础（可能形成专用条件）→ 审定计划/符合性计划表
      → 确定局方保留项目 → 符合性验证（计算/试验/试飞）
      → 制造符合性检查 → TIA → 审定飞行试验 → ICA 与 AFM 批准
      → 符合性检查清单+符合性声明+问题纪要全关闭 → TCDS → 颁 TC
                                    │
                                    │  设计资料成为生产依据
                                    ▼
  C 线：生产机构资格（AP-21-31）
      建生产质量系统与质量手册 → 任命责任经理+质量经理/(安全经理)/生产经理
      → 授权 CS → 编符合性检查清单 → 递交 POA 申请
      → 文件审查（批准质量手册、同意生产试运行）→ 现场审查 → 颁证
      → 批量生产 → 制造符合性声明/批准放行证书 → 适航证
```

关键路径说明：

- **A 线必须先于或至少同步于 B 线的颁证节点**（TC 颁发前局方要确认已取得相应 DOA）。
- **C 线可以在 B 线未完成时启动**：POA 申请人只要"持有或已申请"设计批准即可申请，也可以凭权益转让协议申请；已获 POA 还能先造原型机和试验件。
- **C 线越早建立，B 线的制造符合性检查越少**（AP-21-11R2 §3.8.4：当试验产品在已获批准的生产质量系统生产时，审查组应尽量减少制造符合性检查项目）。

3. 《生产机构许可证申请书》（附表 2）
4. 《项目审定计划》（11 项内容）
5. 申请随附资料：营业执照、资格文件、责任经理与高管履历及培训证明、生产能力说明（人力/生产文件/厂房/工具设备/供应商管理/资质/布局图）
6. 覆盖 QSAC 的体系程序文件：组织管理、设计资料控制、与设计批准方的协调、文件控制、人员能力和资格、供应商控制、制造过程控制、检验和试验、测量设备校准、检验和试验状态、不合格品控制、纠正和预防措施、搬运和存储、质量记录控制、内部审核、交付前维修、使用反馈、质量疏漏、适航性审定、向局方的报告（+ 安全管理要素 s1~s4）
7. **CS 选拔、培训、资质评估、授权、持续监督程序**与 CS 名单
8. （如为试飞）《试飞管理手册 FTOM》
9. 与应用简化条款的说明（限用类无人机：申请只选取必要且适用的 QSAC 准则）

**A/C 线共用的接口文件**

- 设计机构与生产机构**不同法人**时：《权益转让协议》（AP-21-31R3 附表 1 样例），至少覆盖设计机构责任、生产机构责任、双方共同责任（制造偏离与不合格品联合处置、构型控制、协议终止安排）
- **同一法人**时：书面的设计-生产协调与接口程序

### 阶段 3：审定基础与符合性计划

1. 与审查组共同确定**审定基础**（适用规章版次 + 环保要求 + 专用条件 + ELOS + 豁免）；无人机无现成规章适用时，以**项目专用条件**形式确定，并用问题纪要固化；
2. 编制**审定计划（CP）或符合性计划表**（限用类无人机可简化）；逐条给出符合性方法与符合性文件；
3. 划分**符合性表明项目（CDI）**，做风险分级建议（1~4 类风险），确定局方保留项目与非局方保留项目；
4. 确定**制造符合性检查计划**。

**交付物**：审定计划/符合性计划表、符合性检查单（逐条款）、局方保留项目清单、制造符合性检查计划、问题纪要台账。

### 阶段 4：符合性验证

| 活动 | 我方准备 | 局方动作 |
|---|---|---|
| 工程验证试验 | 试验大纲（11 项内容）、**制造符合性声明**（每项试验）、试验产品 100% 制造符合性确认 | 型号资料批准表批大纲 → 制造符合性检查请求单 → 检查 → 按需签发批准放行证书 → 目击 → 试验观察报告 |
| 工程符合性检查 | 构型确认、检查对象准备 | 目击并记录 |
| 分析/计算 | 分析报告、数据有效性证明 | 审查数据分析的准确性、适用性、假设 |
| 申请人飞行试验 | **试验类特许飞行证**、构型控制、制造符合性记录 | 审查飞行试验报告 |
| 安全评估 | FHA、SSA 等 | 审查 |
| 审定飞行试验 | 原型机通过制造符合性检查、为局方试飞员提供机型飞行资格所需飞行时间 | 签发 **TIA** → 审定飞行试验（限用类无人机可不开展） |
| 持续适航文件 ICA | ALI/CMR、SRM、EWIS ICA、WBM 及其他 ICA | 审查组批准/认可 |
| 《航空器飞行手册》AFM | 含 **C2 链路使用限制与程序、遥控台（站）使用限制、运行场景限制**，性能含 C2 链路性能 | 审查组批准 |

### 阶段 5：颁证

颁证前我方必须做到：

- 所有型号资料已审查认可或批准，所有纠正措施已落实；
- **符合性检查清单**（附表 14）覆盖的全部条款均已满足；
- **所有问题纪要均已关闭**；
- 提交**符合性声明**（附表 15）；
- 与审查组共同确认 **TCDS 草案**；
- 设计机构审定审查组的审查结论已出具；
- **已取得相应 DOA**。

颁证后的收尾（3 个月内）：局方完成型号合格审查报告、型号检查报告（TIR）、型号合格审定总结报告，并将项目文档归档。我方需保存型号资料（设计数据、图纸、规范、使用限制、试验大纲与报告、手册初版与修订、服务通告等）**至所有受影响航空器永久退役**。

## 六、风险清单（按文件条款识别的"会踩的坑"）

| 风险 | 文件依据 | 应对 |
|---|---|---|
| 技术熟悉会议材料不真实详细 → 项目进度缓慢 | AP-21-11 §3.6 | 提前编制完整的设计特征说明与新颖特征专题材料 |
| 运行场景描述不清 → 审定基础被"从严裁剪" | AP-21-11 §3.7.1(3) | 场景说明书按风险维度逐项定义，先与局方对齐 |
| DOA/CVE/CS 人员资质不达标（3 年/5 年经验、培训记录缺失） | AP-21-18 附录 C；AP-21-31 §18（1801） | 提前补履历与培训，保留培训与考核证据 |
| 独立监督职能不独立 | AP-21-18 附录 D（一）（二） | 独立监督负责人不得同时承担适航/设计职能 |
| DOA 超期失效（2 年） | AP-21-18 §3.5 | 建立证件台账，届满前 3 个月启动延续 |
