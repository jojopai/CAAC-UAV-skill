## 一、三份文件的关系与无人机适用性

### 1.1 三证之间的关系

```
        ┌─────────────────────────────────────────┐
        │  设计侧：AP-21-11（型号合格审定）        │
        │  产出：型号合格证 TC + 数据单 TCDS       │
        └───────────────────┬─────────────────────┘
                            │ 申请人必须已持有相应的
                            │ 设计机构许可证 DOA 才能颁证
        ┌───────────────────▼─────────────────────┐
        │  设计机构：AP-21-18（DOA）               │
        │  产出：设计机构许可证 + 许可项目单       │
        └───────────────────┬─────────────────────┘
                            │ 设计资料 → 生产依据
        ┌───────────────────▼─────────────────────┐
        │  生产侧：AP-21-31R3（POA）               │
        │  产出：生产机构许可证 + 许可项目单       │
        │  再产出：每架机的制造符合性声明/放行证书 │
        └─────────────────────────────────────────┘
```

### 1.2 三份程序都已明确覆盖无人驾驶航空器

这是本次修订最关键的背景，三份文件都在适用范围里写入了"民用无人驾驶航空器"和"遥控台（站）"：

- **AP-21-11R2 第 1.5 条**：适用于民用航空产品（含民用无人驾驶航空器）及遥控台（站）型号合格证及其更改的申请、受理、审查、颁证和管理。
- **AP-21-18 第 1.5 条**：适用于民用航空产品（含民用无人驾驶航空器）、零部件及遥控台（站）设计机构的 DOA 申请、受理、审查、颁发及对持有人的管理与监督。
- **AP-21-31R3 第 1.5 条**：适用于民用航空产品（含民用无人驾驶航空器）、零部件及遥控台（站）生产机构许可证的申请、受理、审查、颁发及监督管理。

定义上，"民用航空产品：民用航空器（含民用无人驾驶航空器）、航空发动机或者螺旋桨"；"遥控台（站）：遥控民用无人驾驶航空器的各种操控设备（手段）以及有关系统组成的整体"。**遥控台（站）是独立的取证对象**，这一点对我们尤其重要——地面控制站可以单独作为型号合格证的申请对象。

### 1.3 一条对无人机极其重要的捷径：附录 H

AP-21-11R2 **附录 H「轻小型航空器、限用类民用无人驾驶航空器及其遥控台（站）型号合格审定简化程序」** 可直接简化：

1. 审查组可不分设专业/专题组，按项目特点合并；
2. 申请人**可用"符合性计划表"代替审定计划**，逐条列明审定基础、符合性方法、符合性文件，并把局方审查方式分为"资料审查"和"局方参与"两类；
3. **限用类民用无人驾驶航空器无需进行 CCAR-21 部要求的功能可靠性试飞**；
4. **限用类民用无人驾驶航空器可不开展局方审定飞行试验**；
5. 证后设计小改/大改按简化要求批准，但**型号合格证持有人应建立符合 CCAR-21 部的设计小改/大改分类方法和相应管理程序，并获得设计机构审定审查组同意**。

> 结论：如果我们的无人机属于**限用类民用无人驾驶航空器**，整个取证路径、费用和时间都会显著压缩。这取决于飞行器的类别定位与运行场景，属于第一步必须和局方确认的事情。

## 二、AP-21-11R2《型号合格审定程序》要点

### 2.1 五个审定阶段

| 阶段 | 名称 | 主要工作 | 关闭条件 |
|---|---|---|---|
| 一 | 项目受理和启动 | 申请、受理、一般熟悉性介绍 | 受理申请；组建审查组 |
| 二 | 要求确定 | 技术熟悉性会议、确定审定基础、起草问题纪要 | 完成技术熟悉；初步确定审定基础 |
| 三 | 符合性计划制定 | 审查审定计划、确定局方审查重点和方式方法 | 完成审定计划或专项合格审定计划（PSCP） |
| 四 | 符合性确认 | 文件评审、试验目击、审定飞行试验等 | 完成局方审查和确认工作 |
| 五 | 颁证 | 完成型号审查报告、颁发型号合格证 | 完成型号检查报告；颁发 TC |

小项目可压缩或合并阶段；颁证之后还有证后管理阶段。

### 2.2 申请与受理（第 3.2、3.3 条）

申请材料：

1. 按规定格式填写的**申请书（附表 1，表-21-101）**；
2. 申请**航空器**型号合格证：设计特征、三面图、现有基本数据；**无人驾驶航空器还需提交运行场景说明**；
3. 申请航空发动机：设计特征、工作特性曲线、使用限制说明；
4. 申请螺旋桨、**遥控台（站）**：设计特征、工作原理、使用限制说明；
5. 相应的**合格审定取证计划**，如包含重大里程碑计划的项目进度计划。

时限：局方**5 个工作日**内完成申请资料评审；材料不齐的一次性书面通知补正。受理后书面通知（附表 2，表-21-102），指定项目联系人，申请人须按受理通知书要求**缴纳审查费**。

### 2.3 一般熟悉性介绍与技术熟悉性会议（第 3.4、3.6 条）

- 缴费后，局方可安排一般熟悉性介绍，内容包括：产品总体情况、主要设计、特殊产品特性、项目进度、组织机构、主要供应商、构型管理规则、**设计机构（DO）与生产机构（PO）是否分离**。
- 技术熟悉性会议按专业召开，重点是：型号设计特征（尤其是新颖独特设计、非常规用途、新的规章解释或新符合性方法）、建议的审定基础、建议的符合性方法、里程碑计划。
- **不提供真实详细材料会直接导致项目审定进展缓慢**——这是文件里的原话式警告。

### 2.4 审定基础的确定（第 3.7 条）——无人机部分要特别看

审定基础 = 申请之日前有效的适航规章版次 + 环境保护要求 + 专用条件（SC）+ 等效安全水平结论（ELOS）+ 豁免。

针对无人驾驶航空器（第 3.7.1 条第 (3) 项），文件给了两条路径：

1. **局方已颁布**适用于该类别民用无人驾驶航空器、遥控台（站）的适航规章时：以申请之日有效的版次为审定基础；设计更改按《航空产品设计更改审定基础的确定程序》确定。
2. **局方尚未颁布**适用于该类别、或已颁布的规章不能覆盖型号设计特征时：**局方识别与其运行场景对应的运行风险，对已颁布的适航规章进行适用性评估，以项目专用条件的形式确定适用要求**，审查组使用问题纪要将其最终确定为项目审定基础。

第 2 条基本就是我们这类无人机的现实情况：**审定基础是"谈"出来的，谈的依据是我们的运行场景。** 所以运行场景说明书的质量，直接决定审定基础的松紧。

### 2.5 审定计划与符合性方法（第 3.8 条）

审定计划（CP）必须包含：

1. 项目及预期运行类别说明；**无人机还要包括预期运行场景、建议的使用限制**；
2. 建议的审定基础；
3. 如何表明符合性的说明（建议的符合性方法）；
4. 逐条款的**符合性检查单**（含符合性方法和符合性文件）；
5. 负责各条款符合性工作、与审查组对接的人员；
6. 含重大里程碑的项目进度计划。

符合性方法共 10 种代码：

| 代码 | 名称 | 典型用途 |
|---|---|---|
| MC0 | 符合性说明 | 声明性质，无需进一步解释 |
| MC1 | 设计评审 | 技术说明、安装图纸、计算方法 |
| MC2 | 分析/计算 | 载荷、静强度/疲劳、性能、统计数据 |
| MC3 | 安全评估 | FHA、SSA 等 |
| MC4 | 试验室试验 | 静力、疲劳、环境试验 |
| MC5 | 相关产品上的地面试验 | 耐久性、环境试验 |
| MC6 | 飞行试验 | 规章明确要求或其他方法无法完全表明时 |
| MC7 | 工程符合性检查 | 隔离检查、维修规定检查 |
| MC8 | 模拟器试验 | 危险失效情况评估、驾驶舱评估 |
| MC9 | 设备鉴定 | 可包含上述所有方法 |

### 2.6 局方审查范围与深度（第 5.1 条）——决定我们工作量的核心机制

- 申请人把全部符合性验证工作划分为若干**符合性表明项目（CDI）**，逐项做风险等级划分，并向审查组建议直接审查内容。
- 审查组按"新颖的特征 / 复杂程度 / 申请人的能力"三要素评级，再按"发生可能性 × 严重程度"矩阵分为 1~4 类风险：
  - **1 类风险**：非局方保留项目，局方直接接受我们的符合性声明，不审查；
  - **2 类风险**：审查少量符合性报告，少量或不选验证活动目击；
  - **3 类风险**：审查部分符合性报告、目击部分验证活动，数量多于 2 类；
  - **4 类风险**：进一步增加审查与目击数量，并详细审查试验结果分析报告。
- **申请人的能力评价越是"高"，局方保留项目越少。** 而"能力高"的重要依据之一，就是设计保证系统（DOA）的运转记录。
- 申请人应确保审查组能看到非局方保留项目；非局方保留项目出现重大事项（如审定试验中的失效）必须告知审查组，必要时会转为局方保留项目。

### 2.7 制造符合性与试验（第 3.8.4、3.9.1、附录 F）

- 申请人负责识别用于生成符合性数据的试验产品，并对试验产品、试验装置进行 **100% 制造符合性确认**；
- 对每一项验证试验须出具**制造符合性声明（附表 5，表-21-106）**，列出制造偏离并说明不影响试验结果的理由；
- 审查代表通过**制造符合性检查请求单（附表 8，表-21-105）**确定检查项目，检查结果记入**制造符合性检查记录表（附表 6，表-21-107）**，按需签发**批准放行证书（附表 4，AAC-038）**；
- 试验大纲须**在试验前足够长的时间内**提交并获批准（用型号资料批准表，附表 7，表-21-104），大纲至少含 11 项内容（目的、依据、被试产品、设备、测试精度、制造符合性要求、符合性说明、步骤、成功判据、记录项目、异常处理）；
- **当试验产品在已获批准的生产质量系统生产时，审查组应尽量减少制造符合性检查项目**——这是我们尽早建立 POA 的直接收益。

### 2.8 型号检查核准书（TIA）与审定飞行试验（第 3.9.11~3.9.13）

- 审查组完成对申请人试验数据包的审查并确认可接受后，才能签发 **TIA（附表 11，表-21-112）**，同时向申请人发出型号合格审定信函（附表 13，表-21-113）；
- **审定飞行试验只有在签发 TIA 之后才能开始**；
- 申请人做研发飞行试验前，必须为试验航空器取得**试验类特许飞行证**；
- 若审查组不做审定飞行试验，则不用签发 TIA（限用类无人机可走这条路）。

### 2.9 持续适航文件与飞行手册（第 3.9.14、3.9.16 条）

**审查组负责审查并批准**的持续适航文件（ICA）：

1. 适航性限制要求（含 ALI、CMR）；
2. 结构修理手册（SRM）；
3. 电气线路互联系统持续适航文件（EWIS ICA）；
4. 载重平衡手册（WBM）。

其他 ICA 由审查组评审认可。原则上 ICA 批准/认可后才颁证；若需提前颁证，必须满足：审查组负责批准的那部分已获批准，且申请人提交了在交付首架机前或颁发适航证前完成的 ICA 完成计划。

《航空器飞行手册》（AFM）对无人机有专门要求，使用限制须包含：

- **指挥控制链路（C2 链路）的使用限制、操作程序**；
- **遥控台（站）的使用限制**；
- **运行场景限制，包括人口密集程度、隔离飞行等**；

性能部分须包含 **C2 链路的性能**。AFM 及其修订由审查组批准。

### 2.10 颁证前的检查与颁证（第 3.10、3.11 条）

审查组在颁证前必须完成 8 项工作，其中与我们最相关的是：

- 用**符合性检查清单（附表 14，表-21-114）**核查所有适用条款是否满足，所有不符合项均已解决；
- 确认所有**问题纪要均已关闭**；
- 确认申请人提交了**符合性声明（附表 15，表-21-160）**；
- 起草**型号合格证数据单（附表 16，表-21-115）**；
- 完成**型号检查报告**（附表 17，表-21-132，飞行试验部分可延至颁证后 3 个月）；
- **确认设计机构审定审查组的审查结论**。

颁证时限：审定项目监督管理委员会（PSB）建议颁证后，局方审核审查报告，**并确认申请人已获得相应设计机构许可证（DOA）后**，在 **20 个工作日**内决定是否颁证；决定颁证的，自决定之日起 **10 日**内颁发（附表 18，表-21-116）。

> **DOA 是颁发 TC 的前置条件**（有过渡期，见 1.13 节）。

### 2.11 证后更改的批准（第 8 章）

| 情形 | 批准路径 |
|---|---|
| 设计小改 | 由设计机构按 DOA 许可权限批准，按与项目工程师约定的方式报局方备案；超出权限的由项目工程师用型号资料批准表批准 |
| 大改（导致 TC 或 TCDS 更改） | 提交 TC 更改申请，按第 3 章适用步骤审定 |
| 大改（不导致 TC/TCDS 更改） | 书面申请 + 说明性/证明性资料，成立审查组审定，用型号资料批准表批准 |
| 大改（重大更改，需全面实质审查） | 申请新型号合格证 |
| 修理设计（显著影响重量/平衡/强度/可靠性/使用特性/适航性） | 向局方提交批准，审定基础为原 TC 审定基础 |
| 其他修理设计 | 由 DOA 持有人按权限批准，或提交项目工程师批准 |

重大更改的自动判定准则（满足其一）：未保持原有总体构型或构造原理；取证时采用的**前提条件不再有效**。

### 2.12 证书管理与有效期

- TC **长期有效**（除暂扣、吊销、撤销、撤回或局方另行规定终止日期）；
- **申请书有效期**：运输类航空器 5 年，其他航空产品 **3 年**，自申请之日起算；逾期需在到期日前 **20 个工作日**提出新申请或延长申请；
- 应按照新的参考申请日期**重新确认审定基础**；
- TC 可在国内转让（受让人须具有或获得相应 DOA）和跨国转让。

### 2.13 附则的过渡期安排（对我们很关键）

本程序 2026-07-01 生效，对 2026-07-01 前已申请或已取得 TC 的设计机构：

1. **已取得 TC** 的：拟做设计更改的，在 **2027-07-01 前**可按"2026-07-01 前局方同意的方式"获得更改批准，或按本程序批准但**无需满足 DOA 要求**；不做设计更改的，无需申请 DOA。
2. **已申请 TC 但尚未批准**的申请人：在 **2027-07-01 前**可按本程序获得 TC 但**无需满足 DOA 要求**，但 **DOA 的取得不得晚于 2027-07-01**。

> 对我们来说：如果现阶段尚未提交 TC 申请，走的是"先/同步取得 DOA"的路线；如果此前已经递交 TC 申请，则获得了 2027-07-01 之前先拿 TC 的缓冲空间。**首次申请的时间点是重大决策，需要尽快核实并定下来。**

### 2.14 问题纪要机制（附录 A）

问题纪要（附表 3，表-21-103）分 9 类：符合性方法（MC）、等效安全水平（ELOS）、建议的专用条件（SC）、豁免、审定基础（G-1）、符合性确定（G-2）、环境考虑（G-3）、不安全的特征或特性、其他。

形成过程分 4 个阶段：①问题说明（含背景）→ ②审查组立场 → ③申请人立场 → ④结论。

**所有问题纪要必须在颁证前关闭。** 这也是我们需要主动管理的问题清单。

## 三、AP-21-18《设计机构审定和监督程序》要点

### 3.1 DOA 是什么、分几类

设计机构许可证（DOA）是局方颁发的、证明设计机构**已具备满足局方要求的设计保证系统**的批准证件。DOA 由**设计机构许可证**（附表 7）和**设计机构许可项目单**（附表 8）两部分组成。

分两类，**以 1360 kg 最大起飞重量为界**：

| 类别 | 适用对象 |
|---|---|
| **第一类 DOA** | 申请及持有民用涡轮航空发动机和变距螺旋桨，以及**最大起飞重量超过 1360 kg** 的民用航空器 TC 或 STC 的设计机构 |
| **第二类 DOA** | 上述以外的其他民用航空发动机和螺旋桨、**遥控台（站）**，以及**最大起飞重量 1360 kg 或以下**的民用航空器 TC/STC 的设计机构；申请 CTSOA 的原则上第二类 |

两类可自愿升级（第二类可自愿申请第一类）；其他设计批准（MDA、PMA）的设计机构和设计供应商，经局方同意可申请一类或二类。

### 3.2 申请人资格与申请资料（第 3.1 条）

有资格申请的有三类：**设计批准持有人/申请人**、**参与产品设计且承担符合性验证工作的设计供应商**。

首次申请须完整提交：

1. **设计机构许可证申请书**（附表 1）；
2. 公司营业执照复印件；
3. 设计批准证件或**受理通知书复印件**（按申请人类型）；
4. 设计供应商类型：承担符合性验证工作并参与产品设计的证明材料；
5. **项目审定计划建议稿**，其中包含按附录 E 编制的 **DOA 符合性检查单**（对 CCAR-21 部及附录 D 适用要求的符合性检查）；
6. 现有的**设计保证手册**。

受理：局方 **5 个工作日**内评审；受理后按附录 B 规则分配唯一项目受理编号。

### 3.3 审查活动（第 3.2.2 条）需开好五个会

① 审查前审查组内部会议 → ② **首次审查会**（审查组长与**责任经理**参加，就项目审定计划达成一致并共同签字）→ ③ 审查期间会议（可多次）→ ④ 最终审查组内部会议 → ⑤ **末次审查会**（通报审查结果，责任经理参加）。每次会议均须形成会议纪要。

审查方式包括：文件和记录审查、人员资质评估、人员面谈。

### 3.4 颁证与证件有效期

- 局方审议审查报告后决定是否颁证；同意颁发的**在 10 日内颁发 DOA**；不同意的**在 10 个工作日内**出具不予颁证通知并说明理由、告知救济权利；
- **DOA 不得转让**；
- **DOA 自颁发或重新颁发之日起 2 年内有效**；可申请延续，须**在有效期届满前至少 3 个月**提交《设计机构许可证更改申请书》，每次延续 2 年；**超过有效期自动失效，再申请视为初次申请**。

### 3.5 设计保证系统要求（附录 D）

**第一类**要求（较完整）：

1. 任命**责任经理**；
2. 责任经理任命**适航经理**、**独立监督负责人**、**安全经理（如适用）**，以及按需的其他人员；可合并设置，但**独立监督职能必须对设计及适航职能保持独立**；
3. 建立、实施并保持**一类设计保证系统**，包含**安全管理要素**和**设计保证要素**，有明确问责机制和清晰职责分工；
4. **MTOW 超过 1360 kg 的航空器、涡轮航空发动机、变距螺旋桨**的 TC 设计机构，其设计保证系统须涵盖**完整的安全管理要素**：安全政策和安全目标、关键安全人员、安全风险管理过程、安全保证过程（含安全表现评估监测、变更管理、持续改进）、安全促进、**故障失效缺陷事件报告系统**；
5. **设计保证要素**：控制和监督许可项目单范围内的设计/设计更改/修理设计活动的系统（含适航职能）、**独立的核查功能**、供应商管控；
6. 建立**独立的监督功能**，向独立监督负责人和责任经理提供反馈。

**第二类**要求（较简化）：任命责任经理与适航经理（可合并）；建立、实施并保持**二类设计保证系统**；须包含 5 类程序：①设计批准流程管理程序；②设计变更管理程序（含更改分类批准、制造偏离与修理分类批准）；③履行设计批准持有责任的程序；④设计供应商控制程序；⑤故障失效缺陷事件报告系统与资料保存程序。

**设计保证手册**是核心提交物；如开展试飞，还须编制**试飞管理手册**（含试飞流程、机组政策、搭载非机组人员与试飞训练程序、风险与安全管理、机载仪器设备识别程序、试飞文件清单）。

### 3.6 关键岗位与资质（附录 C）

| 角色 | 职责 | 基本资质 |
|---|---|---|
| **责任经理** | 确保机构内所有设计活动按标准进行，持续符合设计保证系统要求和手册程序 | 对相关部门具备直接或经授权管理权限；熟悉适用适航法规与局方设计保证系统要求；参加初始及持续培训 |
| **适航经理** | 由责任经理任命，确保适航职能有效开展 | 3 年以上适航管理岗位经历；熟悉法规与内部要求 |
| **安全经理**（如适用） | 确保安全管理工作有效开展 | 3 年以上安全管理岗位经历 |
| **独立监督负责人** | 确保独立监督职能有效开展 | 3 年以上独立监督相关管理岗位经历 |
| **符合性核查工程师（CVE）** | 对符合性验证资料和活动进行核查并批准 | 公正；熟悉适航法规与体系要求；**5 年以上**符合性规划/验证/表明/审查经历 |
| 其他设计机构授权人员 | 履行许可项目单中的各项审批权利 | 公正；熟悉法规与体系要求；**5 年以上**相关工作经验 |

注意：可合并设置责任经理与上述管理人员，但**独立监督职能的独立性不可妥协**。若许可项目单范围仅限于设计小改和/或未构成大改的修理设计，可不设适航经理，由责任经理直接负责。

### 3.7 证后更改管理（第 3.4 条）

**需申请 DOA 更改**的情形：单位名称、注册地址、设计机构地址、设计保证手册（名称/编号）等任何证件信息，以及涉及许可项目单信息的更改。资料含更改申请书（附表 9）、营业执照、工作范围证明、**更改对设计保证系统的影响评估说明**、修订后的 DOA 符合性检查单、修订后的手册等。受理同样 **5 个工作日**。

**不涉及证件但属"设计保证系统重大更改"**的必须报告 DPI，包括：

- 设计组织：组织机构（含设计供应商）变化、与适航/环保直接相关的机构变更、独立监督原则更改；
- 职责分配：责任经理/适航经理/安全经理/独立监督负责人变更、履行持有人权利人员更换或权限增加、汇报关系变更、职责重新划分；
- 程序变更：12 类影响取证、设计更改分类、适航审批、特许飞行证资料、运行与持续适航文件、构型管控、供应商符合性工作、人员资质授权、信息发布、故障报告、安全风险管理等原则的程序更改；
- 资源：与适航和环保符合性相关的技术人员数量或经验**持续减少**。

重大更改**在得到 DPI 认可时可先行实施**，再按 DPI 要求补充措施；不影响证件且非重大更改的，按 DPI 同意的方式自行管理，在计划性监督中报告。

### 3.8 持续监督（第 4 章）

- **计划性监督**：至少以 **24 个月为 1 个周期**，覆盖 DOA 符合性检查单全部检查项；首次获证后 **1 个月内**制定首个周期监督计划；**每年 11 月 30 日前**编制下一年度年度监督计划（附表 11）；
- **非计划性监督**：蓄意违规、批准的设计出现重大问题、严重偏离体系要求、拒不整改、供应商控制能力严重问题等情形时启动；
- 监督方式：体系执行过程审查、记录审查、模拟案例审查、独立监督记录检查、面谈等；**可视情延伸到供应商处审查，设计机构必须参加**。

### 3.9 不符合项与时限（第 5.3 条）

| 类型 | 定义要点 | 整改时限 |
|---|---|---|
| **一类问题** | 可能导致失控状态并可能造成潜在不安全状态；以及书面要求 2 次及以上仍不让局方接近设施、伪造文件证据、违规使用/冒用 DOA、未任命或任命不合格的责任经理 | 措施落实**不超过 21 个工作日** |
| **二类问题** | 不属于一类问题的其他不符合项 | 措施落实**不超过 3 个月**，可提前申请延期 |
| **观察项** | 未达预期表现、可能导致一/二类问题的潜在情况、改进建议 | 沟通后记录在审定信函中 |

局方在每次审查或监督后 **5 个工作日**内通过审定信函告知结果。若未按要求提交或落实一类问题措施，局方可**暂停体系权利**并通知设计批准审查组；二类问题未落实的，**上升为一类问题**。

### 3.10 DOA 持有人的权利与责任（第 7 章）

权利（在许可项目单范围内）：

1. 批准设计更改/修理设计是"大改"还是"小改"的分类；
2. 批准"声学/非声学""排放/非排放"更改的分类；
3. 按 CCAR-21 部批准**设计小改**；
4. 按 CCAR-21 部批准**未构成设计大改的修理设计**；
5. 经 CVE 核查并批准的符合性验证资料，**局方可无需进一步审查即接受**；
6. 批准试验飞行特许飞行证相关技术资料（含技术状态评估报告、建议的使用限制）。

责任要点：保持手册与体系一致；确认设计/更改/修理符合适用规章和环保要求且无不安全特征；**除按 DOA 权利批准的小改/修理外，向局方提交符合性声明（附表 14）**；提供 CCAR-21.5 事件报告及纠正措施信息；发布信息时注明"本资料由经 CAAC 批准的 ____ 号设计机构许可证持有人按照设计机构许可项目单明确的权利范围进行批准"。

### 3.11 记录保存

审查记录（申请书、受理通知书、项目审定计划、会议纪要、不符合项记录表、纠正措施答复、审定信函、审查报告、许可证等）**至少保存 7 个日历年**。

### 3.12 附则过渡期

1. 2026-07-01 前已取得 TC/STC/CTSOA 的设计机构：拟做设计更改的，应在 **2027-07-01 前**申请并取得 DOA；
2. 2026-07-01 前已申请但未取得的设计机构：**2027-07-01 前**可在未取得 DOA 的情况下获得设计批准，但须满足原有程序中设计保证系统相关要求，并**最晚 2027-07-01 取得 DOA**。

## 四、AP-21-31R3《生产机构审定和监督程序》要点

### 4.1 POA 是什么、谁有资格申请

生产机构许可证（POA）是局方颁发给生产机构的批准文件，表明其**已建立符合 CCAR-21 要求的生产质量系统**，具备按经批准的设计重复生产的能力。POA 由**生产机构许可证**（附表 8）和**生产机构许可项目单**（附表 9）两部分组成，POA 编号由民航局适航审定管理部门统一分配。

申请人资格（满足其一）：

1. 持有或已申请**型号合格证**；
2. 持有或已申请**补充型号合格证或改装设计批准书**；
3. 持有或已申请**技术标准规定项目批准书**；
4. 持有或已申请**局方认可的其他设计批准形式**；
5. 与上述设计批准的申请人或持有人签订**权益转让协议**（附表 1）；
6. 利用中国境内生产设施生产具有型号认可证/补充型号认可证的产品，应持有与相应 TC/STC 持有人的权益转让协议；
7. 运输类航空器（**不含**运输类民用无人驾驶航空器）机体结构大部段供应商、及其发动机单元体供应商，应单独申请 POA；
8. 其他供应商经局方同意也可申请。

注意注释：**已获 POA 的生产机构，亦可接受设计批准申请人委托，在新型号获得设计批准前开展原型机和试验件的生产。**

### 4.2 权益转让协议（第 3.1.3 条）——设计与生产的接口

若设计机构与生产机构不是同一法人，必须签**权益转让协议**，至少包含：

- 设计机构责任：落实适航职责（设计更改提出与批准、制造偏离与不合格品的适航性影响评估）、设计资料的**控制与传递机制**（图纸、规范、标识、材料、工艺、尺寸、表面处理、包装发运条件等，并保证均为经批准的）、识别与追溯信息（名称/编号/版次、用途、安装状态、型号、件号、关键/重要特性标注、使用限制、批准说明、发放日期与授权发放人签署）、技术支持（首件检验、构型控制）；
- 生产机构责任：组织机构与资源配置、试验与验证能力（**航空器生产试飞、发动机/螺旋桨台架试车、完工零部件检验测试**）、按有效设计资料编制作业指导书、在获设计批准前协助原型机/试验件生产、信息反馈机制、协助供应商资料控制、协助持续适航职责（SB、AD、SDR）；
- 双方共同责任：**制造偏离与不合格品的联合处置机制**、构型控制与设计更改传递确认机制、保证重复生产的产品持续符合、协议终止条件与后续安排；
- 协议涵盖的产品范围；
- 是否包括设计机构允许生产机构**直接向最终用户交付**的授权。

> 若设计与生产是同一法人，不需签权益转让协议，但**必须建立书面的协调和接口程序**，规定职责分工与工作衔接。

### 4.3 申请资料（第 3.1.2 条）

1. **生产机构许可证申请书**（附表 2）；
2. CCAR-21 规定的**质量手册**；
3. 申请随附资料：
   - 公司营业执照；
   - 表明具备申请人资格的证书或文件；
   - **责任经理**及其授权高级管理人员（质量经理、安全经理（如适用）、生产经理等）的人员信息、工作经历说明、培训合格证明；
   - 生产能力说明（人力资源、生产文件、厂房设施、工具设备、供应商管理、资质证明、生产设施布局图）；
   - **符合性检查清单**（附录 F）；
   - **建议的项目审定计划**（11 项内容，含组织机构、人员名单与职责、设施地址与产能、体系文件清单、关键供应商清单、审查活动初步计划、DPD 使用情况）。

受理：**5 个工作日**内评审；受理后分配唯一项目受理编号、发受理申请通知书（附表 3），申请人缴费。

### 4.4 审查过程（第 3.2、5.1.3 条）

审查活动分**两个阶段**：

**第一阶段 生产质量系统文件审查**——重点包括：质量手册（须含责任经理声明、高管授权书、组织机构图与部门职责、人力资源概况、生产设施概况、工作范围说明、更改管理、要素管理要求、授权的 CS 名单、与规章条款的符合性索引/矩阵图）；组织上要保证**质量部门能够独立并不受干扰地开展工作**；文件齐全、可行、协调、不模棱两可；**质量疏漏的收集、调查、分析要求**。

确认符合后，审查组长/PI 用审定信函批准质量手册，并**同意开展生产试运行**。

**第二阶段 生产质量系统现场审查**——通过试运行阶段体系运转情况判定符合性；可视情开展**产品审查**；供应商评审记录抽样原则：供应商 ≤20 家抽 3 份，21~50 家抽 6 份，>50 家抽 9 份。

审查会议同样五步：审查前审查组会议 → **首次审查会**（责任经理及高管参加，共同签字确认项目审定计划）→ 审查期间会议 → 最终审查组会议 → **末次审查会**。

### 4.5 原型机与试验件的生产（第 3.2.3 条）

设计批准申请人委托已持 POA 的生产机构，在新型号获设计批准前生产原型机/试验件，双方须签权益转让协议（含所依据的设计技术资料、构型管理与确认、制造偏离评审处理、委托的制造符合性检查项目及要求、生产和检查记录要求）。

POAH 应协助设计批准申请人确认原型机/试验件符合所依据的设计并出具质量证明文件；有偏离的提交设计批准申请人评审处理。若拟在 POA 范围内开展，应申请将尚未获设计批准的型号增列至许可项目单并标注"**原型机**"。

**注意：POA 生产质量系统下生产的原型机、试验件，在其设计获得批准前不得交付民航运营。**

### 4.6 颁证与有效期

- 审查组长向局方提交生产机构审定项目审查报告；民用航空器项目须先提交 **PSB** 作出是否建议颁证的结论；
- 颁证后审查组即行解散；
- **POA 不得转让**；符合条件时 **POA 长期有效**（持续符合 CCAR-21、接受检查、有效控制、未放弃、所生产产品的设计批准有效）。POA 被撤销/吊销或持有人放弃时须交回证书。

### 4.7 持证人的权利（第 3.5 条）

1. 开展许可范围内的生产活动；
2. 对按批准设计生产的**民用航空器**进行技术检查，提交责任经理或其授权人签署的**航空器制造符合性声明**（附表 10），经局方检查确认后**可获得适航证或出口适航证**；
3. 对按批准设计生产的发动机、螺旋桨、零部件、**遥控台（站）**，由授权的**生产放行人员（CS）签发"批准放行证书"**（附表 17）；
4. 经设计批准审查组同意生产原型机/试验件时，由 CS 签发制造符合性的批准放行证书；
5. 对其生产的、尚未交付民航运营的产品进行维修；
6. 申请生产试飞、交付试飞特许飞行证时，对所生产航空器实施技术检查，提交检查结论、飞行条件和使用限制后可获得特许飞行证。

### 4.8 证后监督管理（第 4 章）

- **生产状态**：过去 12 个月内开展过生产/交付或原型机、试验件生产活动的为**"活跃"**；否则为"非活跃"，由活跃转非活跃应书面报告 PI。**非活跃状态无需开展生产管理与监督活动**；转回活跃须接受**生产质量系统复查（QSRA）**。
- **最低审查频次**：活跃状态 POAH **每 2 年至少开展一次日常监督审查**。
- 日常监督三类型：**生产质量系统复查（QSRA）、供应商控制审查（SCA）、主管监察员审查（PIA）**，均为**基于产品**的系统审查。
- **随机监督**：含生产质量系统重要更改审查（12 类情形，如单位名称/注册地址更改、设施地址更改扩大、产能范围更改、**责任经理及高管更换或职责调整**、CS 更换、组织机构重大调整、质量手册换版、供应商管理方式重大调整等）、质量问题调查、非计划审查。
- SCA 通知：开展 SCA 前**至少提前 20 天**通知 POAH，由 POAH 通知被审查供应商。

### 4.9 生产质量系统审查准则（QSAC）

**质量管理要素共 20 项**（附录 D）：0 组织管理(4) / 1 设计资料控制(10) / 2 与设计批准申请人或持有人的协调(2) / 3 文件控制(3) / 4 人员能力和资格(2) / 5 供应商控制(14) / 6 制造过程控制(26) / 7 检验和试验(33) / 8 检验、测量和试验设备的校准和控制(6) / 9 检验和试验状态(3) / 10 不合格品控制(7) / 11 纠正措施和预防措施(1) / 12 搬运和存储(8) / 13 质量记录控制(1) / 14 内部审核(2) / 15 交付前维修(3) / 16 使用反馈(4) / 17 质量疏漏(2) / 18 适航性审定(11) / 19 向局方的报告(3)。

**安全管理要素共 4 项**（附录 E，适用正常类/运输类民用无人驾驶航空器等）：s1 安全政策、目标和资源(3) / s2 安全风险管理(3) / s3 安全保证(6) / s4 安全促进(2)。**允许与质量管理要素融合建设**，以减少重复建设。

> **对限用类无人驾驶航空器及其发动机、螺旋桨和遥控台（站）的 POA 申请人或持有人，局方可采用基于风险的适航审定原则，只选取其中必要且适用的审查准则开展生产质量系统审查。** 这是我们做体系文件时可以直接申请的简化。

### 4.10 生产放行人员（CS）与放行文件

- **CS 资质**：至少 **5 年**民用航空产品质量管理、生产制造、适航管理或工程技术相关工作经验，熟悉适航法规和质量管理体系要求；须参加局方规定的初始培训和持续培训（适航法规基础、专业基础、专业培训、知识更新等），**接受局方面试和必要考核**；须有**正式书面授权文件**，并接受初始评估与定期复评、持续监督。
- **交付航空器**：提交**航空器制造符合性声明**，须表明该航空器严格按局方批准的生产质量系统生产、完成全部所需工作、符合经批准的设计并处于安全可用状态；须经 DAH 确认所有型号设计资料均已获局方批准；须做实物检查（机身外部、机翼、起落架/轮舱、发动机、驾驶舱/客舱等）；试飞报告须由相应 CS 和一名机组成员签署；签署人应为 POAH 责任经理或其授权人员。
- **交付其他产品**：须取得批准放行证书。

### 4.11 不符合项与整改时限（第 5.5 条）

| 类型 | 提交纠正措施答复 | 完成整改 |
|---|---|---|
| **涉及安全的不符合项** | 不超过 **5 个工作日**（并立即采取措施消除不安全因素、立即停止相关产品放行和交付、必要时通报用户） | **20 个工作日**内（或局方要求的更短期限） |
| **系统性不符合项 - 严重** | **5 个工作日**内提交并获认可 | 纠正措施完成期限经局方同意，一般**不超过 3 个月** |
| **系统性不符合项 - 一般** | **20 个工作日**内提交并获认可 | 同上 |
| **孤立不符合项** | 不超过 **30 个工作日** | 同上 |

纠正措施完成前，若生产质量系统有效性无法满足规章要求、不能保证产品适航性，**将影响其放行和交付**。

### 4.12 记录保存与报告义务

- 审查及监督管理过程中产生的所有文件和记录，由责任人在审查活动结束后移交局方统一归档，**保存期不少于 15 个日历年**（通过信息化系统存储的可不再另行归档）；
- **第 19 节 向局方的报告**：出现列明的 13 类故障/失效/缺陷情形（着火、发动机排气系统故障、驾驶舱/客舱有毒有害气体、螺旋桨操纵系统故障、桨叶结构损坏、易燃液体渗漏、刹车系统失效、主要结构严重缺陷、异常振动、发动机失效、降低飞行品质的操纵系统故障、发电/液压系统完全失效、空速/姿态/高度仪表故障等）时，**在确认后 48 小时内（含周末和节假日）向局方提交报告**；同时须报告生产质量系统重要更改。

### 4.13 附则过渡期

1. 2026-07-01 前已取得**生产许可证（PC）**的项目：可继续按 PC 生产和交付；已受理的 PC 增项/更改申请仍可获批；但应在 **2027-07-01 前申请并完成 PC 转 POA**（接受必要补充审查，无需向 PSB 报告）。**2027-07-01 后 PC 不再有效。**
2. 2026-07-01 前已申请但尚未取得 PC 的，按本程序管理。
3. 运输类航空器（**不含**运输类民用无人驾驶航空器）机体结构大部段、发动机单元体制造人，应在 2027-07-01 前申请并获得 POA。

> 对我们的意义：**"生产许可证（PC）"这个名称已经退出，新体系叫"生产机构许可证（POA）"**，且历史上由《轻小型航空器生产许可及适航批准审定程序》管理的轻小型航空器生产许可内容已并入本程序。

## 八、把三份文件落到我们项目上的结论

1. **取证是一个"三证联动"的工程**：型号合格证（TC）+ 设计机构许可证（DOA）+ 生产机构许可证（POA）。TC 的颁发以取得相应 DOA 为前提（过渡期除外），批量生产交付以 POA 为前提。
2. **遥控台（站）是独立取证对象**，需要单独准备设计特征、工作原理、使用限制说明，并可能单独申请 TC 或纳入许可项目单。
3. **运行场景说明书是我们最重要的技术文件之一**，它决定局方如何评估运行风险、如何把已颁布规章"裁剪"成项目专用条件，也就是决定我们最终要符合哪些条款。
4. **DOA 的类别由最大起飞重量 1360 kg 划分**；DOA 有效期仅 2 年，需要建立常态化的体系维护与延续申请机制。
5. **体系能力直接换审查强度**：申请人能力评价越高，局方保留项目越少；DOA 运转记录、CVE 的工作记录是直接依据。
6. **限用类民用无人驾驶航空器有实质简化空间**：免功能可靠性试飞、可不做局方审定飞行试验、可用符合性计划表代替审定计划、POA 可只选必要且适用的审查准则。
7. **过渡期到 2027-07-01**，这是三份文件共同给出的时间窗口，我们所有计划都应在这个日历上排布。
8. **处罚与整改是硬约束**：一类问题 21 个工作日、涉及安全的不符合项 5 个工作日答复/20 个工作日整改、故障失效 48 小时报告，这些必须内建到我们的程序里。
