## 三、建议的阅读与执行顺序

```
第一步  读 04（弄清我们属于哪一类、走哪条路线）
          ↓
第二步  填 03（把事实补齐，特别是最大起飞重量、是否载人、运行区域人口密度）
          ↓
第三步  写 05（运行场景说明书——它是审定基础的源头）
          ↓
第四步  按 06 搭两套体系文件（设计保证手册 + 质量手册）
          ↓
第五步  按 02 排里程碑，同期递交 TC / DOA / POA 三份申请
          ↓
贯穿    用 01 查条款、时限、表号
```

## 四、最需要先确定的三件事

1. **最大起飞重量是否超过 25 kg**——不超过 25 kg 则无需适航许可，整件事不适用。
2. **是否载人 / 是否融合飞行 / 是否在人口密集区域上方飞行**——三者全"否"才能走限用类，否则要走正常类甚至运输类。
3. **是否能在 2027-07-01 前递交型号合格证申请**——这决定能否利用 DOA 的过渡期便利。
