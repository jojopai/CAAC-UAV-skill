## 三、第一步：定类别（AC-21-40 的分级分类）

### 3.1 按重量分档

按《条例》第六十二条与 AP-21-71 的定义（已核对原文）：

| 类别 | 判定条件 |
|---|---|
| 微型 | 空机重量＜0.25 kg，最大飞行真高≤50 m，最大平飞速度≤40 km/h，无线电发射设备符合微功率短距离技术要求，全程可随时人工介入操控 |
| 轻型 | 空机重量≤4 kg **且**最大起飞重量≤7 kg，最大平飞速度≤100 km/h，具备空域保持和可靠被监视能力，全程可随时人工介入操控（不含微型） |
| 小型 | 空机重量≤15 kg **且**最大起飞重量≤25 kg，具备空域保持和可靠被监视能力，全程可随时人工介入操控（不含微型、轻型） |
| **中型** | **最大起飞重量＞25 kg 且 ≤150 kg** |
| **大型** | **最大起飞重量＞150 kg** |

《条例》第八条：从事**中型、大型**民用无人驾驶航空器系统的设计、生产、进口、飞行和维修活动，应当依法向国务院民用航空主管部门**申请取得适航许可**；从事微型、轻型、小型的相应活动**无需取得适航许可**，但产品应符合产品质量法律法规和强制性国家标准。

**因此：如果我们产品的最大起飞重量不超过 25 kg，则 TC / DOA / POA 这一整套工作都不适用**——这是必须最早确认的事实。

再按 CCAR-92 部第 92.343 条的分类定义（已核对原文）：

| 类别 | 定义 |
|---|---|
| 正常类 | 除运输类外，最大审定起飞重量 **25 公斤及以上**，可用于载人飞行、进行融合飞行或者在人口密集区域上方飞行 |
| 运输类 | 最大审定起飞重量 **5700 公斤（固定翼）或 3180 公斤（旋翼类）以上**，或者载客 19 人以上，可用于载人飞行、进行融合飞行或者在人口密集区域上方飞行 |
| 限用类 | 最大审定起飞重量 **25 公斤及以上**，**不用于载人飞行、不进入融合空域飞行且不在地面人员稠密区域飞行** |

### 3.2 危害严重性级别（AC-21-40 第 7.1 条）

以最大审定起飞重量为基准，结合最大使用限制速度算出的动能：

| 级别 | 判定 |
|---|---|
| **Ⅰ 级** | 5700 kg（固定翼）或 3180 kg（旋翼类）以上 |
| **Ⅱ 级** | 750～5700 kg（固定翼）或 3180 kg（旋翼类）；150～750 kg 且动能＞1084 千焦 |
| **Ⅲ 级** | 150～750 kg 且动能 ≤1084 千焦；25～150 kg 且动能＞100 千焦 |
| **Ⅳ 级** | 25～150 kg，且动能 ≤100 千焦 |

（原文按上述文字表述，旋翼类在 Ⅱ 级的上界表述为 3180 kg，严谨取值以原件为准。）

### 3.3 运行风险等级 A～G（AC-21-40 第 7.3 条）

**不载人、隔离飞行**时，按"稀疏区／密集区"分：

| 严重性级别 | 稀疏区 | 密集区 |
|---|---|---|
| Ⅰ | C | A |
| Ⅱ（含以 2720 kg 为界的细分） | D / E | B / C |
| Ⅲ | F | D |
| Ⅳ | G | E |

**载人**时按乘员数量分：Ⅰ级任意乘员数为 A；Ⅱ级 1~2 人 C、3~6 人 C、7~9 人 B、10~19 人 A；Ⅲ级 1~2 人 C。

**不载人但进行融合飞行**的：运行风险等级**不应低于**表中相同严重性级别、在人口密集区隔离飞行的等级。

## 四、第二步：定路线（AP-21-71 第 1.4 条）

这是整件事的分水岭：

### 路线一：正常类 / 运输类

**触发条件**：用于**载人飞行**、进行**融合飞行**、或在**人口密集区域上方**飞行的中型和大型无人机。

- 属于危害严重性 **Ⅰ 级或载客 19 人以上** → 按**运输类**进行型号合格审定
- 属于危害严重性 **Ⅱ～Ⅳ 级** → 按**正常类**进行型号合格审定

证件链：**型号合格证 TC + 生产许可证 + 民用无人驾驶航空器标准适航证**

### 路线二：限用类（我们最可能走的路）

**触发条件**：**不用于载人飞行、不进行融合飞行、且不在人口密集区域上方飞行**的中型和大型无人机。

- 证件链：**型号合格证 TC + 生产许可证 + 民用无人驾驶航空器特殊适航证**
- **限用类只能获得特殊适航证，并且必须在局方规定的限制条件下飞行**
- 审定基础的形成方式：**充分考虑运行场景 → 识别运行风险 → 对已颁布适航标准做适用性评估 → 增加遥控台（站）、数据链等无人机特有要求 → 以专用条件形式确定**，作为型号合格审定基础

### 路线三：中型农用无人机的特殊便利（若适用）

同时满足以下全部条件的中型农用无人机（MTOW≤150 kg、最大飞行真高≤30 m、最大平飞速度≤50 km/h、最大飞行半径≤2000 m、具备空域保持和可靠被监视能力、专门用于植保播种投饵等农林牧渔作业、作业中可随时人工介入）：

- 局方**原则上只进行设计保证系统审查**，并**直接接受申请人在局方授权下依托设计保证系统开展的产品型号合格审定结论**；
- 也可**仅通过表明符合特定试飞要求取得特许飞行证**，即获得适航批准。

### 两条路线对比

| 项目 | 限用类 | 正常类 / 运输类 |
|---|---|---|
| 申请受理单位 | **所在地区管理局** | 按 AP-21-11 流程 |
| 审定程序依据 | AP-21-71 + AP-21-11 适用部分 | AP-21-11（+AP-21-71 适用要求） |
| 审定基础 | 运行风险 + 适用性评估 + 专用条件 | 已颁布的相关类别适航标准 |
| 生产批准依据 | AP-21-31（AP-21-32 内容已并入） | AP-21-31 |
| 适航证类型 | **特殊适航证**（有限制条件） | **标准适航证** |
| 运行限制 | 只能在局方规定的限制条件下飞行 | 无此特别限制 |
| 申请书有效期 | **3 年** | 其他产品 3 年 / 运输类 5 年 |

## 五、AP-21-71 程序要点

### 5.1 申请（限用类向所在地区管理局提交）

申请材料：

1. 按规定格式填写的**申请书**（附表 1）；
2. 对设计保证系统的**符合性说明或建设情况说明**；
3. 产品的**设计说明、主要技术数据、预期运行场景及与之对应的风险类别和使用限制**；所装发动机的设计特征、工作特性曲线和使用限制说明；所装螺旋桨的设计特征、工作原理和使用限制说明；
4. （申请 STC 时）型号设计更改内容说明；
5. **建议的审定基础**；
6. **建议的审定计划**。

受理：局方 **5 个工作日**内完成评审；材料不齐一次性书面通知补正；受理后缴费。

### 5.2 设计保证系统（比 AP-21-18 简化）

AP-21-71 要求建立并保持设计保证系统，具有：

1. **适航职能**——确保设计符合适用适航标准和环保要求；
2. **独立的符合性核查职能**；
3. **独立的制造符合性检查功能**；
4. **独立监督职能**——监督对手册程序的符合性与充分性，并有向落实纠正措施部门反馈的机制；
5. **供应商管理**。

人员要求：**责任经理**（有权支配本单位人员、财产和设备）、**适航经理**（直接向责任经理报告）、**符合性核查工程师**（不得核查自己完成的特定设计；优先推荐有与局方共同参与符合性验证经验者）。

符合性核查工程师资质（AP-21-71）：工程专业学历 + 航空相关工程知识与经历；**从事航空工程设计或试飞活动至少 3 年以上**。

设计保证系统的权利：

1. 在审定过程中根据局方授权进行符合性判断；
2. 在局方授权且未列入局方审查范围的领域，**局方直接接受其符合性判断**；
3. 按经局方认可的程序确认设计更改类别，**确认为设计小改的可自行表明符合性、无需报局方批准**；
4. 对超出持续适航文件规定且判断为重大设计更改的修理，根据局方授权批准修理方案。

### 5.3 审查流程

熟悉性介绍 → 组建审查组 → **设计保证系统审查（文件评审 + 人员面谈 + 现场审查）** → 确定审定基础 → 审定计划与符合性方法（MC0~MC9）→ 制造符合性检查 → 符合性验证与确认（工程验证试验、工程符合性检查、工程分析、飞行试验）→ 型号资料审查 → **审批持续适航文件（ALI/CMR、SRM、WBM）** → **审批《民用无人驾驶航空器系统飞行手册》** → **最终全面评审** → 颁发设计批准证书 → 文件存档 → 证后管理。

最终全面评审的 7 项（与 AP-21-11 基本一致）：型号资料审查状态核查、符合性检查清单核查、**问题纪要全部关闭**、**设计符合性声明**、起草数据单、**对设计保证系统给出最终审查结论**、编写型号审查报告。

《民用无人驾驶航空器系统飞行手册》的使用限制须包含：**运行场景限制（人口密集程度、隔离飞行等）**、空速限制、重量重心与配载限制、动力装置限制、最大使用高度与载荷系数等。

### 5.4 适航批准（第四部分）——取证链条的最后一段

| 证件 | 适用对象 |
|---|---|
| **标准适航证** | 取得型号合格证的**正常类、运输类**无人机 |
| **特殊适航证** | 取得型号合格证的**限用类**无人机；用于特定运行场景，在特定限制条件下飞行且没有不安全特征 |
| **特许飞行证** | 为证明符合适航标准进行试验飞行、执行生产试飞/交付试飞、按局方要求完成试飞的中型农用无人机、局方认为必要的其他用途 |
| **出口适航证** | 拟出口的无人机（不得作为批准运行的文件） |

一般要求：**申请适航批准的无人机应已完成实名登记或国籍登记**；申请人应是所有人或占有人。

标准适航证申请资料：适航证申请书、与批准构型的差异说明（如适用）、制造符合性声明、使用过的还需提交履历资料（日历时间/飞行小时/飞行循环、维护方案与执行情况、重大故障、改装与修理批准情况、零部件更换批准情况）、持续适航文件清单等。受理 5 个工作日。

**关键便利**：对于**依据生产许可证（即 POA）制造的新无人机，局方核查申请资料后无需进行适航检查**；依据 TC 生产的则需开展交付状态现场适航检查。这再次说明尽早取得生产机构许可证的价值。

适航证管理：**可随无人机系统一起转让**；在中国注册登记期间、按规定维修并按运行限制运行的情况下**长期有效**；相关文件保存至航空器注销后 2 年。

## 六、限用类适航标准（AC-21-AA-2026-44）要点

### 6.1 适用范围

符合以下限制的限用类民用无人驾驶航空器系统的型号设计及其更改：

1. 《条例》规定的**中型**无人机系统；
2. 《条例》规定的、**最大起飞重量小于 3180 kg 的大型**无人机系统。

申请人**可以使用附件 1 中的适航标准作为适用的型号合格审定基础**。符合 CCAR-92 第 92.327 条规定情形的，局方将按 AP-21-17 制定相应**专用条件**。

### 6.2 标准结构（三大部分）

**第 1 部分 基本要求**

- 1.1 术语定义（最小飞行重量、最大起飞重量）
- 1.2 设计特征及运行场景
  - 基本特征（三视图、尺寸、重量重心、飞行包线、主要系统）、功能描述（飞控、通信、导航、任务）
  - 各飞行阶段、预期运行环境（降雨/降雪/结冰/风/沙尘/温度/湿度/电磁干扰/辐射干扰/闪电/HIRF）及载重状态下的性能数据与使用限制
  - 各子（分）系统基本信息、架构框图、规格参数、安全保护逻辑
  - 标记与标牌信息说明
  - **构型文件**（图纸、技术规范及清单、结构强度所需尺寸/材料/工艺资料）
  - **运行场景**：预期用途、使用环境，明确**预设飞行区域**（起降场、航线等）和**应急恢复区域**（应急处置航线、备降点、迫降点或坠机区域等）的划设原则
- 1.3 整机要求
  - 机体结构：工程评估（强度分析）和试验验证，表明能承受使用寿命期内预期重复载荷，**机体寿命限制列入持续适航文件**
  - **飞行重要零部件**：建立清单（系统与设备类 + 机体结构类），制定强制性维护说明、寿命限制或组合
  - 无线电设备：设计批准不含频率使用许可
  - **防破解能力**（须经验证）
- 1.4 使用限制和资料：标记和标牌、**飞行手册**、**持续适航文件**

**第 2 部分 通用测试科目**

- 2.1 基本要求（试验要求、数据有效性、飞行试验大纲和报告）
- 2.2 性能测试科目：性能测试、可控性测试、环境测试、**指挥控制链路性能测试**

- 2.4 **失效分析测试科目**：系统安全分析、**GNSS 中断**、操纵机构失效、**临界动力失效**、**指挥控制链路丧失/中断**、**遥控台（站）失效**、空中和地面风险缓解能力测试
- 2.5 功能和可靠性测试

| 多旋翼 | 悬停性能测试 |

## 七、与三份 2026 程序的关系，以及需要向局方澄清的冲突点

### 7.1 关系

- AP-21-11R2（2026）已把无人机纳入适用范围，并给了附录 H 简化程序（限用类无人机免功能可靠性试飞、可不做局方审定飞行试验）；
- AP-21-71（2022）是无人机**专用**程序，额外给出了适航证件的完整路径（标准/特殊适航证、特许飞行证、出口适航证）；
- AP-21-31R3（2026）已把原 AP-21-32《轻小型航空器生产许可及适航批准审定程序》的生产许可内容并入；
- AP-21-18（2026）新设了设计机构许可证（DOA）制度，把设计保证系统的要求规范化。

### 7.2 需要澄清的不一致（准备在与局方预沟通时提出）

| 事项 | AP-21-71（2022） | 2026 年三份程序 | 建议处理 |
|---|---|---|---|
| 符合性核查工程师年限 | 至少 **3 年**航空工程设计或试飞经历 | AP-21-18 附录 C 要求 **5 年**符合性相关工作经历 | 按更严的 5 年准备，避免资质不达标 |
| 设计保证系统岗位 | 责任经理、适航经理、符合性核查工程师 | 增加**安全经理**（如适用）与**独立监督负责人** | 按 AP-21-18 设置全套岗位 |
| 生产批准依据 | 限用类参照 AP-21-32 | AP-21-32 的生产许可内容已并入 **AP-21-31R3** | 以 AP-21-31R3 为准 |
| 专用条件程序编号 | 引用 AP-21-21 | 引用 **AP-21-17** | 以 AP-21-11R2 引用的 AP-21-17 为准 |
| 申请书有效期 | 限用类 **3 年** | 运输类 5 年、其他 3 年 | 一致，无冲突 |

AP-21-71 未废止，且其关于**类别划分原则**和**适航证件分类**的内容是三份 2026 程序没有覆盖的，因此实际是以"A/B 两条线叠加"的方式适用。上述不一致处属于新旧文件衔接问题，**建议在预沟通会上一次性确认**，避免后续返工。

## 八、对决策点 D1~D5 的更新

原来的五个决策点现在可以更精确地问：

| 编号 | 更新后的问法 | 依据 |
|---|---|---|
| **D1** | 最大起飞重量是否 **≥25 kg**？若否，整个适航取证不适用 | 《条例》第八条、第六十二条；CCAR-92 第 92.343 条 |
| **D2** | 是否载人 / 是否融合飞行 / 是否在人口密集区域上方飞行？三者全"否"才能走**限用类** | AP-21-71 第 1.4(1)(2) |
| **D3** | 危害严重性级别是 Ⅰ/Ⅱ/Ⅲ/Ⅳ 哪一级（按 MTOW 与动能）→ 运行风险等级 A~G 哪一级 | AC-21-40 第 7 章 |
| **D4** | 是否满足中型农用无人机的 5 项条件（若是，可只审设计保证系统） | AP-21-71 第 1.4(3) |
| **D5** | 是否可在 **2027-07-01 前**递交 TC 申请，以利用 DOA 的过渡期便利 | AP-21-11R2、AP-21-18 附则 |

补充两个新决策点：

| 编号 | 问题 | 影响 |
|---|---|---|
| **D6** | 是否已在 2026-07-01 前递交过 TC 申请 | 决定能否先拿 TC、DOA 最晚 2027-07-01 |
| **D7** | 运行区域是否包含人口密集区（即使只是"可能经过"） | 一旦沾上密集区，就必须走正常类/运输类，工作量和成本量级不同 |

## 九、一句话总结

**我们的取证依据 =《无人驾驶航空器飞行管理暂行条例》第八条（要不要取证）+ CCAR-21/CCAR-92（按什么规则）+ AP-21-71 与 AC-21-40（分到哪个类别、走哪条路线）+ 限用类或正常类适航标准与项目专用条件（技术条款）+ AP-21-11R2 / AP-21-18 / AP-21-31R3（申请、审查、颁证、监督的流程）+ 实名登记与事件报告等配套规定（运行前提与义务）。**
