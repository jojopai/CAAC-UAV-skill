# 《设计保证手册》与《质量手册》框架

依据：AP-21-18 附录 D（设计保证系统要求）与附录 C（资格要求）、AP-21-AA-2022-71 附录 A（设计保证系统要求）、AP-21-31R3 第 5.1.3 条（质量手册必备内容）与附录 D/E（QSAC 质量要素 20 项、安全要素 4 项）。

---

## 一、两份手册的定位

| | 《设计保证手册》（DAM） | 《质量手册》（QM） |
|---|---|---|
| 服务于 | 设计机构许可证（DOA）申请 | 生产机构许可证（POA）申请 |
| 覆盖活动 | 设计、设计更改、修理设计及其符合性验证 | 按经批准的设计进行制造、检验、试验、放行 |
| 体系名称 | 设计保证系统（含设计保证要素 + 安全管理要素） | 生产质量系统（质量要素 + 安全要素） |
| 批准方式 | 审查组/DPI 用**审定信函**批准手册及覆盖的体系文件清单 | 审查组组长/PI 用**审定信函**批准质量手册，并同意生产试运行 |
| 关键岗位 | 责任经理、适航经理、（安全经理）、独立监督负责人、符合性核查工程师 | 责任经理、质量经理、（安全经理）、生产经理、生产放行人员（CS） |
| 与我方关系 | 决定"我们能不能自己批小改、局方能不能直接采信我们的符合性判断" | 决定"能不能批量生产、能不能自己签发批准放行证书" |

> 两者**可以融合建设**：AP-21-31R3 附录 E 明确允许把安全管理要素与质量管理要素融合，减少重复建设。建议共用一套"组织与职责""文件控制""记录控制""培训授权""内部审核""不符合项与纠正措施""事件报告"程序，只在专业章节上分设。
