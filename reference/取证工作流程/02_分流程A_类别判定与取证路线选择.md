## 3 判定规则表（可直接照表执行）

### 3.1 第一道门：是否需要适航许可

| 类别 | 判定条件（《条例》第六十二条） |
|---|---|
| 微型 | 空机重量＜0.25 kg；真高≤50 m；平飞速度≤40 km/h；微功率短距离无线电；全程可随时人工介入 |
| 轻型 | 空机重量≤4 kg 且 MTOW≤7 kg；平飞速度≤100 km/h；具备空域保持与可靠被监视能力；全程可随时人工介入 |
| 小型 | 空机重量≤15 kg 且 MTOW≤25 kg；具备空域保持与可靠被监视能力；全程可随时人工介入 |
| **中型** | **MTOW＞25 kg 且 ≤150 kg** |
| **大型** | **MTOW＞150 kg** |

→ 微型/轻型/小型：**无需适航许可**，本流程体系（B/C/D/E）不适用。
→ 中型/大型：须申请适航许可，继续下一步。

### 3.2 第二道门：类别（路线）

| 路线 | 判定条件 | 证件组合 | 适航证类型 |
|---|---|---|---|
| **限用类** | 不用于载人飞行、不进入融合空域飞行且不在地面人员稠密区域飞行（MTOW≥25 kg） | TC + 生产许可证 + 特殊适航证 | **特殊适航证**（须在局方规定限制条件下飞行） |
| **正常类** | 除运输类以外，MTOW≥25 kg，可用于载人飞行、进行融合飞行或在人口密集区域上方飞行 | TC + 生产许可证 + 标准适航证 | 标准适航证 |
| **运输类** | MTOW≥5700 kg（固定翼）或 ≥3180 kg（旋翼类），或者载客 19 人以上，可用于载人/融合/密集区 | TC + 生产许可证 + 标准适航证 | 标准适航证 |

### 3.3 第三道门：危害严重性级别与运行风险等级

**危害严重性级别（AC-21-40 第 7.1 条）**

| 级别 | 判定 |
|---|---|
| Ⅰ 级 | 5700 kg（固定翼）或 3180 kg（旋翼类）以上 |
| Ⅱ 级 | 750～5700 kg（固定翼）或 3180 kg（旋翼类）；150～750 kg 且动能＞1084 千焦 |
| Ⅲ 级 | 150～750 kg 且动能≤1084 千焦；25～150 kg 且动能＞100 千焦 |
| Ⅳ 级 | 25～150 kg 且动能≤100 千焦 |

**运行风险等级（AC-21-40 第 7.3 条）**

不载人、隔离飞行：

| 严重性级别 | 稀疏区 | 密集区 |
|---|---|---|
| Ⅰ | C | A |
| Ⅱ | D / E | B / C |
| Ⅲ | F | D |
| Ⅳ | G | E |

载人：Ⅰ级任意乘员数为 A；Ⅱ级 1~2 人 C、3~6 人 C、7~9 人 B、10~19 人 A；Ⅲ级 1~2 人 C。

不载人但融合飞行：运行风险等级**不应低于**同严重性级别在人口密集区隔离飞行的等级。

### 3.4 特殊便利路径：中型农用无人机

需同时满足（P1 第1.4(3)条）：

1. 最大起飞重量不超过 150 kg；
2. 最大飞行真高不超过 30 m；
3. 最大平飞速度不超过 50 km/h；
4. 最大飞行半径不超过 2000 m；
5. 具备空域保持能力和可靠被监视能力，专门用于植保、播种、投饵等农林牧渔作业，作业过程中可随时人工介入操控。

满足时：局方**原则上只进行设计保证系统审查**，并直接接受申请人在局方授权下依托设计保证系统开展的产品型号合格审定结论；**也可仅通过表明符合特定试飞要求取得特许飞行证**获得适航批准。

## 4 控制点 G1

| 检查项 | 通过标准 |
|---|---|
| 重量分档结论 | 有产品设计数据支撑，结论明确 |
| 三个"是否"的判定依据 | 运行场景说明书已明确人口密集程度、隔离/融合飞行、是否载人 |
| 严重性级别与运行风险等级 | 有计算过程与查表记录 |
| 类别与路线结论 | 明确是限用类还是正常类/运输类 |
| 局方确认 | 有预沟通记录 |

## 5 常见错误与风险

| 风险 | 后果 | 规避措施 |
|---|---|---|
| MTOW 定义用错（用空机重量或典型起飞重量代替最大起飞重量） | 类别判错 | 严格使用"根据设计或使用限制，无人驾驶航空器正常起飞所容许的最大重量" |
| 运行区域描述为"一般不进入人口密集区"但未排除"可能飞经" | 被要求按正常类审定 | 用地理围栏等技术手段排除进入密集区的可能性，并在说明书中写实 |
| 忽略"融合飞行"的判定 | 路线判错 | 明确空域性质与是否有其他航空器同时运行 |
| 动能计算口径不清 | 严重性级别判错 | 按最大审定起飞重量与最大使用限制速度计算，保留计算过程 |
| 误以为限用类不需要设计保证系统 | 申请被退回 | 限用类同样需要设计保证系统（CCAR-92 第92.323条） |
