# 04 分流程 C：设计机构许可证（DOA）审定流程

文件编号：UAV-CERT-C
版次：Rev.0
上游流程：UAV-CERT-A（类别与路线）
下游流程：UAV-CERT-B（TC 颁证前置）、UAV-CERT-F（证后管理）
主要依据：P3（AP-21-18）、L3（CCAR-21）、P1 第2节（DAS 要求）

---

## 1 流程图

```
开始
 │
 ├─ C-S01 确定 DOA 类别
 │        第一类：涡轮航空发动机、变距螺旋桨、MTOW＞1360 kg 的航空器 TC/STC 设计机构
 │        第二类：其他发动机与螺旋桨、遥控台(站)、MTOW≤1360 kg 的航空器 TC/STC 设计机构、CTSOA
 │
 ├─ C-S02 建体系：编制《设计保证手册》+ 配套程序文件
 │        一类：设计保证要素 + 完整安全管理要素（安全政策/目标、关键安全人员、
 │              安全风险管理、安全保证、安全促进、事件报告）
 │        二类：二类设计保证系统（5 类程序）
 │
 ├─ C-S03 任命关键岗位：责任经理、适航经理、(安全经理)、独立监督负责人
 │        ※ 独立监督职能必须对设计及适航职能保持独立
 │
 ├─ C-S04 任命并授权符合性核查工程师（CVE）及其他授权人员
 │        ※ 资质：建议按 5 年符合性相关工作经历准备（详见第4节冲突说明）
 │
 ├─ C-S05 编制《DOA 符合性检查单》（对照 CCAR-21 部 + AP-21-18 附录D 逐条）
 │
 ├─ C-S06 编制项目审定计划建议稿（含许可项目审定计划）
 │
 ├─ C-S07 递交 DOA 申请（6 项资料）→ 5 个工作日受理
 │
 ├─ C-S08 首次审查会（责任经理参加，与审查组长共同签字确认审定计划）
 │
 ├─ C-S09 设计保证系统审查（文件与记录审查 + 人员资质评估与面谈）
 │
 ├─ C-S10 不符合项整改（一类 21 个工作日 / 二类 3 个月）
 │
 ├─ C-S11 末次审查会 → 审查组完成《设计机构审定项目审查报告》
 │
 ├─ C-S12 局方审议 → 同意后 10 日内颁发 DOA（许可证 + 许可项目单）→ Gate M1
 │
 └─ C-S13 证后管理（转流程F）
```

5. 项目审定计划建议稿（含按附录 E 编制的 DOA 符合性检查单）

## 4 需要特别注意的两处依据冲突

| 事项 | AP-21-71（2022） | AP-21-18（2026） | 本流程采用 |
|---|---|---|---|
| 符合性核查工程师年限 | 从事航空工程设计或试飞活动**至少 3 年** | 具备与授权专业相关**至少 5 年**符合性规划/验证/表明/审查工作经历 | **按 5 年准备**（更严标准，避免资质不达标） |
| 体系岗位设置 | 责任经理、适航经理、CVE | 增加**安全经理（如适用）**与**独立监督负责人** | **按 AP-21-18 设置全套岗位** |

→ 该冲突应在与局方预沟通时确认，并在设计保证手册中明确说明按哪一版执行。

| 权利 3 | 按 CCAR-21 部批准**设计小改** | P3 第7.1(3)条 |

## 6 输出物清单

1. 设计机构许可证 + 设计机构许可项目单（DOA）
2. 经审定信函批准的《设计保证手册》及体系文件清单
3. DOA 符合性检查单、项目审定计划
4. 授权人员清单（CVE 及其他授权人员）
5. 全部审查记录（申请书、受理通知书、会议纪要、不符合项记录表、纠正措施答复、审定信函、审查报告）
