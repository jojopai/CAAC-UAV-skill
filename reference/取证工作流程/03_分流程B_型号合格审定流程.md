# 03 分流程 B：型号合格审定流程

文件编号：UAV-CERT-B
版次：Rev.0
上游流程：UAV-CERT-A（类别与路线）
下游流程：UAV-CERT-E（适航批准）、UAV-CERT-F（证后管理）
主要依据：L2 第92.321~92.349条；P1（AP-21-71）；P2（AP-21-11R2）；A2~A6

## 1 流程图

```
┌─ 限用类路线 ────────────────────────────────────────────────────────┐
│  向所在地区管理局提交：申请书 + DAS说明 + 设计说明/技术数据/运行场景/  │
│  风险类别/使用限制 + 建议审定基础 + 建议审定计划                      │
│  → 5 个工作日受理 → 缴费 → 熟悉性介绍 → 组建审查组                    │
└──────────────────────────────┬──────────────────────────────────────┘
┌─ 正常类/运输类路线 ──────────▼──────────────────────────────────────┐
│  依据 AP-21-11R2 的适用部分 + AP-21-71 的适用要求开展申请与审查         │
└──────────────────────────────┬──────────────────────────────────────┘
                               ▼
        B-S01 设计保证系统审查（文件评审 + 人员面谈 + 现场审查）
                               ▼
        B-S02 确定审定基础
              （已颁布标准 → 用标准；未颁布/不覆盖 → 运行风险+适用性评估
                +遥控台(站)/数据链要求 → 专用条件）
                               ▼
        B-S03 审定计划（CP / 符合性计划表）+ 符合性方法 MC0~MC9
                               ▼
        B-S04 基于风险确定审查范围与深度 → 局方保留项目清单
                               ▼
        B-S05 制造符合性检查（试验产品 100% 确认 + 制造符合性声明）
                               ▼
        B-S06 符合性验证与确认
              ├ 工程验证试验（大纲审批→制造符合性→目击→报告）
              ├ 工程符合性检查
              ├ 工程分析
              └ 飞行试验（特许飞行证 → 研发试飞 → TIA → 审定飞行试验）
                               ▼
        B-S07 型号资料审查（评审表 / 批准表 / 问题纪要）
                               ▼
        B-S08 审批持续适航文件（ALI/CMR、SRM、WBM）
                               ▼
        B-S09 审批《民用无人驾驶航空器系统飞行手册》
                               ▼
        B-S10 最终全面评审（7 项）
                               ▼
        B-S11 签发颁证建议 → Gate K1
                               ▼
        B-S12 颁发型号合格证 + 型号合格证数据单
                               ▼
        B-S13 文件存档 → B-S14 证后管理（转流程F）
```

## 3 关键控制点

| 控制点 | 名称 | 通过条件 | 依据 |
|---|---|---|---|
| K1 | 颁证前置条件 | 已取得相应 DOA；所有型号资料获审查认可或批准；符合性检查清单全部满足；问题纪要全部关闭；已提交符合性声明 | P2 第3.10、3.11条 |
| K2 | 试验放行 | 制造符合性声明已提交、局方检查完成、偏离已处理 | P2 第3.9.1(3)(4)条 |
| K3 | 试飞放行 | 已取得 TIA（审定飞行试验）或试验类特许飞行证（研发试飞） | P2 第3.9.4、3.9.11条 |

## 4 限用类简化对照（附录 H 带来的调整）

| 常规要求 | 限用类简化 | 依据 |
|---|---|---|
| 需编制完整审定计划 | 可用"符合性计划表"代替（逐条列明审定基础、符合性方法、符合性文件；审查方式分"资料审查"与"局方参与"） | P2 附录H 第3.2条 |
| 审查组分设专业/专题组 | 可不分设，按项目特点合并 | P2 附录H 第3.1条 |
| 需做功能和可靠性试飞 | **无需进行** CCAR-21 部要求的功能可靠性试飞 | P2 附录H 第3.4条 |
| 需开展局方审定飞行试验 | **可不开展** | P2 附录H 第3.5条末段 |
| 证后小改/大改 | 型号合格证持有人应建立小改/大改分类方法与程序并经设计机构审定审查组同意 | P2 附录H 第3.5条 |

## 5 输出物清单

1. 型号合格证（TC）+ 型号合格证数据单（TCDS）
2. 审定基础文件（含专用条件、ELOS 结论、豁免）
3. 批准的审定计划 / 符合性计划表
4. 符合性检查清单、符合性报告、符合性声明
5. 问题纪要汇编（全部关闭）
6. 批准的持续适航文件与《民用无人驾驶航空器系统飞行手册》
7. 型号审查报告、型号检查报告、型号合格审定总结报告

## 6 常见退回原因

| 序号 | 问题 | 依据 |
|---|---|---|
| 1 | 运行场景说明不完整，未给出与之对应的风险类别和使用限制 | P1 第3.1(3)条 |
| 2 | 设计保证系统未建立或手册未覆盖符合性核查与独立监督 | L2 第92.323条 |
| 3 | 审定计划缺少符合性检查清单或方法说明不足 | P2 第3.8.1条 |
| 4 | 试验大纲缺少 11 项必备内容之一 | P2 第3.9.1(1)条 |
| 5 | 试验前未提交制造符合性声明或未处理制造偏离 | P2 第3.9.1(3)(4)条 |
| 6 | 未取得特许飞行证即开展飞行试验 | P2 第3.9.4条 |
| 7 | 颁证前仍有未关闭的问题纪要 | P2 第3.10(3)条 |
| 8 | 飞行手册缺 C2 链路与遥控台（站）使用限制 | P2 第3.9.16条 |
