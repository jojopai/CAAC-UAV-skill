版次：Rev.0

主要依据：P1（AP-21-71）第四部分；L2 第92.301、92.305条；P5（实名登记管理程序）

## 1 流程图

```
开始（逐架机）
 │
 ├─ E-S01 完成实名登记或国籍登记（申请适航批准的前提）
 │
 ├─ E-S02 按经批准的设计生产、检验、试验
 │
 ├─ E-S03 判定本架机适用哪一类适航证件
 │        ├ 取得 TC 的正常类/运输类 → 标准适航证
 │        ├ 取得 TC 的限用类       → 特殊适航证
 │        ├ 尚未取证/需试验飞行     → 特许飞行证
 │        └ 拟出口                 → 出口适航证
 │
 ├─ E-S04 交付航空器：技术检查 + 签署《航空器制造符合性声明》
 │        （交付其他产品：由授权 CS 签发《批准放行证书》）
 │
 ├─ E-S05 向局方提交适航证申请书及资料 → 5 个工作日受理 → 缴费
 │
 ├─ E-S06 局方适航检查
 │        ├ 依据生产许可证（POA）制造的新机 → 核查资料后【无需适航检查】
 │        └ 依据型号合格证生产的新机 → 文件记录评审 + 交付状态现场适航检查
 │
 ├─ E-S07 颁发适航证 → Gate P1
 │
 └─ E-S08 文件存档（至航空器注销后 2 年）
```

## 2 适航证件分类与适用

| 证件 | 适用对象 | 依据 |
|---|---|---|
| **标准适航证** | 取得型号合格证的**正常类、运输类**无人机系统 | P1 第4.1条 |
| **特殊适航证** | 取得型号合格证的**限用类**无人机系统；重点关注与预定运行场景和特定限制条件相关的符合性内容 | P1 第4.2条 |
| **特许飞行证** | ① 为证明符合适航标准进行试验飞行的系统；② 执行生产试飞、交付试飞的新系统；③ 按局方要求完成试飞的中型农用无人机；④ 局方认为必要的其他用途 | P1 第5条 |
| **出口适航证** | 拟出口的无人机系统（**不得作为批准其运行的文件**） | P1 第6条 |

**限用类的三条硬性禁止**：取得特殊适航证的限用类无人机系统，应当在局方规定的限制条件下飞行，并且**不得用于载人飞行、不得进行融合飞行、不得在人口密集区域上方飞行**。（P1 第4.2条）

### 3.4 特许飞行证

申请资料（P1 第5.1条）：

1. 《民用无人驾驶航空器特许飞行证申请书》（附表 14）
2. 申请飞行任务情况说明及建议的使用限制
3. 民用无人驾驶航空器系统技术与批准状态的报告
4. 《制造符合性声明》（如适用）（附表 4）
5. 局方认为必要的其他文件

（中型农用无人机：仅需特许飞行证申请书 + 按局方要求完成试飞的试飞报告）

| 步骤 | 活动 | 责任方 | 输出 | 时限 | 依据 |
|---|---|---|---|---|---|
| E-S05a | 递交特许飞行证申请 | 我方→局方 | 受理通知 | 局方 5 个工作日内决定是否受理 | P1 第5.2条 |
| E-S05b | 局方适航检查：必要检查、确认安全措施已正确实施、评估使用限制建议、核实检查与试验记录 | 局方 | 特许飞行证检查记录单（附表 16） | — | P1 第5.3条 |
| E-S05c | 科研/符合性验证试飞用途及中型农用无人机：局方**原则上基于申请人完成的工作颁发**，如无特殊原因**不开展现场检查** | 局方 | — | — | P1 第5.3(6)条 |
| E-S07d | 局方确认安全可用状态后颁发特许飞行证 | 局方 | 特许飞行证（附表 19） | — | P1 第5.4条 |

**特许飞行的限制**（P1 第5.5条）：

1. 运行前应符合登记管理相关要求；
2. 不得用于以营利为目的的运输或作业飞行，不得因补偿或出租而载运人员和货物（局方另有规定除外）；
3. 不得载运人员，除非是与该次特许飞行相关并已被告知授权内容和适航状态的人员；
4. 应由知晓该次特许飞行情况、要求与措施并持有相应执照的人员操控；
5. 应遵守相应飞行规则，并**避开空中交通繁忙区域、人口密集区域以及可能对公众安全造成危害的区域**；
6. 应在飞行手册规定的性能限制及局方对该次特许飞行提出的其他限制条件下进行。

**有效期**：由局方规定；除非另有需要，局方不再另外限定科研/符合性验证试飞用途及中型农用无人机的特许飞行证有效期。（P1 第5.6条）

## 4 适航证的更换与重新颁发

| 情形 | 处理 | 依据 |
|---|---|---|
| 适航证再次签发记录已填满 | 申请**更换** | P1 第4.3(1)条 |
| 适航证破损或丢失 | 申请**更换** | P1 第4.3(1)条 |
| 适航证被吊销 | 申请**重新颁发** | P1 第4.3(2)条 |
| 无人机系统型别发生变化 | 申请**重新颁发** | P1 第4.3(2)条 |

## 5 适航证的转让性与有效期

- 适航证**可以随无人机系统一起转让**；
- 在中国注册登记期间，除非被暂停、吊销或局方另行规定终止日期，在按照各项规定进行维修并按照各项运行限制运行时，**适航证长期有效**；
- 依据：P1 第4.4条。

## 6 关键控制点

| 控制点 | 名称 | 通过条件 | 依据 |
|---|---|---|---|
| P1 | 登记前置 | 已完成实名登记或国籍登记 | P1 第四部分第3节(1) |
| P2 | 交付放行 | 航空器制造符合性声明已签署（含实物检查），试飞报告已由 CS 与机组成员签署 | P4 附录D 第1802条 |
| P3 | 限用类三条禁止 | 运行场景与限制条件符合特殊适航证要求 | P1 第4.2条 |
| P4 | 特许飞行合规 | 避开繁忙空域与人口密集区域；不用于营利性运输 | P1 第5.5条 |

1. 标准适航证 / 特殊适航证 / 特许飞行证 / 出口适航证

## 8 常见退回原因

| 序号 | 问题 | 依据 |
|---|---|---|
| 1 | 未完成实名登记或国籍登记即申请适航批准 | P1 第四部分第3节(1) |
| 2 | 制造符合性声明填写信息与 POA/许可项目单不一致 | P4 附录D 第1802(4)条 |
| 3 | 与经批准构型存在差异却未提交差异说明 | P1 第4.1.1(2)条 |
| 4 | 持续适航文件不完整或失效 | P1 第4.1.3(3)(a)(ⅴ) |
| 5 | 限用类系统拟载人或进入人口密集区域运行 | P1 第4.2条 |
| 6 | 特许飞行用于营利性运输或载运无关人员 | P1 第5.5(2)(3)条 |
