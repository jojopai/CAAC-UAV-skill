# 05 分流程 D：生产机构许可证（POA）审定流程

文件编号：UAV-CERT-D
版次：Rev.0
上游流程：UAV-CERT-A
下游流程：UAV-CERT-E（适航批准）、UAV-CERT-F（证后管理）
主要依据：P4（AP-21-31R3）、L3（CCAR-21）、L2 第92.305(c)(1)(i)条

---

## 1 流程图

```
开始
 │
 ├─ D-S01 确认申请人资格（满足其一）
 │        持有/已申请 TC、STC或MDA、CTSOA、其他局方认可的设计批准形式；
 │        或与设计批准申请人/持有人签订权益转让协议
 │
 ├─ D-S02 确定设计与生产的关系
 │        ├ 同一法人 → 编制书面的设计-生产协调与接口程序
 │        └ 不同法人 → 签订《权益转让协议》（附表1）
 │
 ├─ D-S03 建体系：编制《质量手册》（含责任人声明、高管授权书、组织机构图、
 │        人力资源、生产设施、工作范围、更改管理、20项QSAC要素、CS名单、
 │        与规章条款符合性矩阵）
 │
 ├─ D-S04 任命责任经理、质量经理、(安全经理)、生产经理
 │
 ├─ D-S05 授权生产放行人员（CS）并建立 CS 管理程序
 │
 ├─ D-S06 编制《符合性检查清单》（附录F）与项目审定计划（11 项）
 │
 ├─ D-S07 递交 POA 申请 → 5 个工作日受理 → 缴费
 │
 ├─ D-S08 首次审查会（责任经理及高管参加，共同签字确认审定计划）
 │
 ├─ D-S09 【第一阶段】生产质量系统文件审查
 │        └ 通过后：审定信函批准质量手册 + 同意生产试运行
 │
 ├─ D-S10 生产试运行
 │
 ├─ D-S11 【第二阶段】生产质量系统现场审查（含产品审查、供应商评审记录抽样）
 │
 ├─ D-S12 不符合项整改（涉及安全：5个工作日答复/20个工作日整改；
 │        系统性：严重5个工作日、一般20个工作日答复；孤立：30个工作日）
 │
 ├─ D-S13 末次审查会 → 编制《生产机构审定项目审查报告》
 │        → 民用航空产品项目须先报 PSB 作出颁证建议
 │
 ├─ D-S14 颁发 POA（生产机构许可证 + 许可项目单）→ Gate N1
 │
 └─ D-S15 证后管理（转流程F）
```

### 2.2 申请与受理

申请资料（P4 第3.1.2条）：① 生产机构许可证申请书（附表 2）；② CCAR-21 规定的质量手册；③ 随附资料：营业执照、表明资格的证书或文件、责任经理及授权高管的人员信息与工作经历及培训合格证明、生产能力说明（人力资源、生产文件、厂房设施、工具设备、供应商管理、资质证明、生产设施布局图）、符合性检查清单（附录 F）、建议的项目审定计划。

### 2.4 不符合项整改

| 类型 | 答复时限 | 整改完成 | 依据 |
|---|---|---|---|
| 涉及安全的不符合项 | **5 个工作日**内提交纠正措施答复 | **20 个工作日**内（或局方要求更短） | P4 第5.5.2(1)条 |
| 系统性不符合项 - 严重 | **5 个工作日**内提交并获认可 | 一般不超过 3 个月 | P4 第5.5.2(2)条 |
| 系统性不符合项 - 一般 | **20 个工作日**内提交并获认可 | 一般不超过 3 个月 | P4 第5.5.2(2)条 |
| 孤立不符合项 | **30 个工作日**内提交 | — | P4 第5.5.2(3)条 |

涉及安全的不符合项须**立即**采取措施消除不安全因素、**立即停止相关产品的放行和交付**，必要时通报受影响用户/运营人，并提供受影响的用户/运营人清单。

## 3 关键控制点

| 控制点 | 名称 | 通过条件 | 依据 |
|---|---|---|---|
| N1 | POA 颁证 | 文件审查通过、现场审查通过、不符合项已关闭或已制定经认可的实施计划 | P4 第3.2.2(d)、3.3条 |
| N2 | 质量部门独立性 | 组织机构设置保证质量部门能够独立并不受干扰地开展工作 | P4 第5.1.3(1)(c)2)条 |
| N3 | CS 资质 | 5 年以上相关工作经验；参加局方规定培训；经局方面试与考核；有正式书面授权 | P4 附录D 第1801条 |
| N4 | 原型机/试验件交付门禁 | 设计获批准前**不得交付民航运营** | P4 第3.2.3条注、第3.5条注 |
| N5 | 涉及安全不符项处置 | 立即停线停交付 + 5 个工作日答复 + 20 个工作日整改 | P4 第5.5.2(1)条 |

## 4 原型机与试验件的特别路径

若在新型号获得设计批准前需要生产原型机/试验件：

1. 设计批准申请人与已持 POA 的生产机构签订**权益转让协议**（须含所依据的设计技术资料、构型管理与确认要求、制造偏离评审处理方式、委托的制造符合性检查项目及要求、生产和检查记录要求）；
2. POAH 协助设计批准申请人确认原型机/试验件符合所依据的设计并出具质量证明文件；
3. 存在偏离时提交设计批准申请人评审处理；
4. 若拟纳入 POA 范围，应申请将尚未获设计批准的型号增列至许可项目单并标注"**原型机**"；
5. **原型机/试验件在设计获批准前不得交付民航运营**。

## 5 与设计侧的接口要求（权益转让协议要点）

| 责任方 | 关键责任 |
|---|---|
| 设计机构 | 落实适航职责（设计更改提出与批准、制造偏离与不合格品的适航性影响评估）；建立设计资料控制与传递机制（图纸、规范、标识、材料、工艺、尺寸、表面处理、包装发运条件），保证均为经批准版本；提供识别与追溯信息（名称/编号/版次、用途、安装状态、型号、件号、关键/重要特性标注、使用限制、批准说明、发放日期与授权发放人签署）；提供首件检验、构型控制等技术支持 |
| 生产机构 | 组织机构与资源配置；试验与验证能力（航空器生产试飞、发动机/螺旋桨台架试车、完工零部件检验测试）；按有效设计资料编制作业指导书；获设计批准前协助原型机/试验件生产；信息反馈机制；协助供应商资料控制；协助持续适航职责（SB、AD、SDR） |
| 双方共同 | 制造偏离与不合格品**联合处置机制**；构型控制与设计更改传递确认机制；保证重复生产产品持续符合；协议终止条件与后续安排（在制品处置、已交付产品持续支持、技术资料归档移交） |

## 6 输出物清单

1. 生产机构许可证 + 生产机构许可项目单（POA）
2. 经审定信函批准的《质量手册》及程序文件清单
3. 授权的 CS 名单
4. 权益转让协议（或同法人间的接口程序）
5. 符合性检查清单、项目审定计划、审查情况通知书、制造符合性检查记录表
6. 生产机构审定项目审查报告

## 7 常见退回原因

| 序号 | 问题 | 依据 |
|---|---|---|
| 1 | 质量手册缺少必备内容（如责任经理声明、高管授权书、符合性矩阵图、CS 名单） | P4 第5.1.3(1)(c)1)条 |
| 2 | 质量部门不能独立开展工作 | P4 第5.1.3(1)(c)2)条 |
| 3 | 不同法人却未签订权益转让协议 | P4 第3.1.3条 |
| 4 | CS 未取得正式书面授权或未接受局方面试考核 | P4 附录D 第1801条 |
| 5 | 供应商管理方式重大调整未报告（如授权供应商开展关键特性不合格品审理、直接发货） | P4 第4.4.1条 |
| 6 | 直接发货授权未事先报局方审查、补偿措施缺失 | P4 第5.2.1(2)条 |
| 7 | 原型机/试验件在获设计批准前交付运营 | P4 第3.2.3条注 |
| 8 | PC（生产许可证）未在 2027-07-01 前转换为 POA | P4 附则 |
| 9 | 飞机制造符合性声明未做实物检查或未由责任经理/授权人签署 | P4 附录D 第1802条 |
