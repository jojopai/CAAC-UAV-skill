# 01 总流程：无人机适航取证端到端

文件编号：UAV-CERT-01
版次：Rev.0
适用：中型、大型民用无人驾驶航空器系统的适航取证
主要依据：L1、L2、P1~P7、A1~A7

---

## 1 总体流程图

```
┌─────────────────────────────────────────────────────────────────────┐
│ 阶段 0  判定                                                        │
│   └─ 重量分档 → 类别判定 → 取证路线选择                              │
│      输出：《取证类别与路线判定报告》                                 │
│      Gate G1：类别与路线经局方预沟通确认                              │
├─────────────────────────────────────────────────────────────────────┤
│ 阶段 1  体系建立（并行三条线）                                        │
│   ├─ 设计保证系统（→DOA）        ┐                                   │
│   ├─ 产品设计与符合性规划（→TC）  ├─ Gate G2：体系文件可提交           │
│   └─ 生产质量系统（→POA）        ┘                                   │
│      输出：设计保证手册、质量手册、运行场景说明书、审定计划建议稿等       │
├─────────────────────────────────────────────────────────────────────┤
│ 阶段 2  申请与受理（并行递交三份申请）                                 │
│   ├─ TC 申请 + DOA 申请 + POA 申请                                  │
│   └─ 各 5 个工作日内完成受理评审                                      │
│      Gate G3：三份申请均已受理并缴费                                  │
├─────────────────────────────────────────────────────────────────────┤
│ 阶段 3  审查                                                         │
│   ├─ 一般/技术熟悉性介绍与会议                                       │
│   ├─ 确定审定基础（含专用条件）                                       │
│   ├─ 审定计划 / 符合性计划表 → 确定局方保留项目                        │
│   └─ DOA 审查、POA 审查（文件审查 + 现场审查）                        │
│      Gate G4：审定制订完成且三线审查均无阻断性不符合项                  │
├─────────────────────────────────────────────────────────────────────┤
│ 阶段 4  符合性验证                                                   │
│   ├─ 工程验证试验（大纲批准 → 制造符合性 → 目击 → 报告）               │
│   ├─ 工程符合性检查、分析/计算、安全评估                              │
│   ├─ 申请人飞行试验（须先取得试验类特许飞行证）                        │
│   ├─ TIA → 审定飞行试验（限用类可不开展）                             │
│   └─ ICA 与飞行手册编制报批                                          │
│      Gate G5：符合性检查清单全部条款满足、问题纪要全部关闭              │
├─────────────────────────────────────────────────────────────────────┤
│ 阶段 5  颁证                                                         │
│   ├─ TC 颁发（以取得 DOA 为前提）                                    │
│   └─ POA 颁发                                                        │
│      Gate G6：TC 与 POA 双证在手                                     │
├─────────────────────────────────────────────────────────────────────┤
│ 阶段 6  适航批准（逐架机）                                            │
│   ├─ 制造 → 制造符合性声明 / 批准放行证书                              │
│   └─ 适航证（标准/特殊）或特许飞行证                                   │
├─────────────────────────────────────────────────────────────────────┤
│ 阶段 7  证后管理（长期）                                              │
│   ├─ 设计更改、修理设计、生产质量系统更改                              │
│   ├─ 设计保证系统计划性/非计划性监督、POA 日常/随机监督                 │
│   └─ 故障失效缺陷报告、持续适航                                      │
└─────────────────────────────────────────────────────────────────────┘
```

| 过渡期截止（DOA/PC 转换） | 2027-07-01 | P2、P3、P4 附则 |

## 4 并行关系与关键路径

```
流程A ──► 流程C（DOA）──┐
   │                     ├──► TC 颁发 ──► 流程E（适航证）
   └──► 流程B（TC）──────┘
   │
   └──► 流程D（POA）─────────────────► 批量生产交付
                                              │
                    流程F（证后管理）◄─────────┘
```

- **流程 C（DOA）是关键路径上的前置**：TC 颁发前须确认已取得相应 DOA（过渡期条款除外）。
- **流程 D（POA）宜尽早启动**：POA 建立后，TB 阶段（流程 B）的制造符合性检查项目可被减少。
- **流程 A 是所有流程的前提**：类别错，全盘错。

## 5 控制点（Gate）汇总
