## 专用条件

专用条件按具体型号逐个制定，编号形如 `SC-92-xxx`。撰写时建议参照已公开发布的样例，例如翼龙-2气象型无人驾驶航空器系统专用条件（SC-92-001）。

## 检索技巧

民航局信息公开检索接口为 `https://www.caac.gov.cn/was5/web/search`，常用参数：

| 参数 | 含义 |
| --- | --- |
| `channelid=211383` | 全站 |
| `channelid=238066` | 规范性文件 |
| `channelid=269689` | 民航规章 |
| `sw=<关键词>` | 关键词，需 URL 编码 |
| `perpage=50` | 每页条数 |

示例，检索"限用类无人驾驶航空器系统适航标准"：

```bash
curl -sS "https://www.caac.gov.cn/was5/web/search?page=1&channelid=238066&sw=%E9%99%90%E7%94%A8%E7%B1%BB%E6%97%A0%E4%BA%BA%E9%A9%BE%E9%A9%B6%E8%88%AA%E7%A9%BA%E5%99%A8"
```

结果页中的详情页链接形如 `.../GFXWJ/202602/t20260226_230117.html`，附件为同目录下的 `P020...pdf`。下载后即可交给 `build_corpus.py`。
