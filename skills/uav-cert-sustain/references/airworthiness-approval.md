# Airworthiness approval and delivery release

依据 P1 第四部分，以及 L2 第92.301条 与 L2 第92.305条(c)。
This runs once per aircraft, so treat it as a procedure with a checklist.

## Which certificate applies

| Certificate | Applies to | Note |
| --- | --- | --- |
| 标准适航证 | 取得型号合格证的正常类、运输类系统 | P1 第4.1条 |
| 特殊适航证 | 取得型号合格证的限用类系统 | P1 第4.2条，须在局方规定的限制条件下飞行 |
| 特许飞行证 | 试验飞行、生产试飞、交付试飞；中型农用；局方认为必要的其他用途 | P1 第5条 |
| 出口适航证 | 拟出口的系统 | P1 第6条，不得作为批准运行的文件 |

限用类的三条禁止随特殊适航证生效：不得用于载人飞行、不得进行融合飞行、
不得在人口密集区域上方飞行。依据 P1 第4.2条。

## Preconditions

| # | Requirement | Source |
| --- | --- | --- |
| 1 | 已完成实名登记或国籍登记 | P1 第四部分第3节(1); P5 |
| 2 | 申请人是该系统的所有人或占有人；出口适航证申请人可为出口人 | P1 第四部分第3节(2) |

## Standard / special airworthiness certificate

Application documents, 依据 P1 第4.1.1条：

1. 民用无人驾驶航空器适航证申请书，P1 附表13
2. 与经批准构型的差异说明，如适用
3. 制造符合性声明，P1 附表4
4. 使用过的系统另附履历资料：日历时间、飞行小时、飞行循环；维护方案及执行情况；重大故障发生与处理；重要改装与修理项目的适航批准情况；零部件更换的适航批准情况
5. 持续适航文件清单，如适用
6. 局方认为必要的其他材料

受理：局方在收到申请书后 5 个工作日内作出是否受理的决定，依据 P1 第4.1.2条。

适航检查有两种情况，务必先区分：

- 依据生产许可证（POA）制造的新机：局方核查申请资料后无需进行适航检查，依据 P1 第4.1.3条(2)。
  这是尽早取得 POA 的直接收益，也是减少重复工作的最大单点。
- 依据型号合格证生产的新机：须进行文件记录评审与交付状态现场适航检查，依据 P1 第4.1.3条(3)。

特殊适航证参照标准适航证执行，局方重点关注与预定运行场景和特定限制条件相关的符合性内容，
依据 P1 第4.2条。

## Delivery release

| Product | Release document | Source |
| --- | --- | --- |
| 民用航空器 | 航空器制造符合性声明，经局方检查确认后取得适航证或出口适航证 | P4 第3.5条(2); P4 附录D 第1802条 |
| 发动机、螺旋桨、零部件、遥控台（站） | 由授权的 CS 签发批准放行证书 | P4 第3.5条(3) |
| 经同意生产的原型机、试验件 | 由授权的 CS 签发制造符合性的批准放行证书 | P4 第3.5条(4) |

签署航空器制造符合性声明前的实物检查至少覆盖机身外部、机翼、起落架与轮舱、发动机、
驾驶舱与客舱，确认标识、外观、功能与多余物情况。试飞报告须由相应 CS 与一名机组成员签署。

在设计获得批准前，POA 生产质量系统下生产的产品不得交付民航运营，依据 P4 第3.2.3条注 与 P4 第3.5条注。

## 特许飞行证

For research or conformity flight test, and for production or delivery flight test.

| Item | Rule |
| --- | --- |
| 申请材料 | 申请书 P1 附表14、飞行任务情况说明及建议的使用限制、技术与批准状态报告、制造符合性声明如适用，依据 P1 第5.1条 |
| 受理 | 5 个工作日内决定是否受理，依据 P1 第5.2条 |
| 现场检查 | 科研与符合性验证试飞用途、中型农用无人机，局方原则上基于申请人完成的工作颁发，如无特殊原因不开展现场检查，依据 P1 第5.3条(6) |
| 运行限制 | 不得用于以营利为目的的运输或作业飞行；不得载运无关人员；应避开空中交通繁忙区域与人口密集区域，依据 P1 第5.5条 |
| 有效期 | 由局方规定；科研与符合性验证试飞用途、中型农用无人机，除另有需要外不再另限有效期，依据 P1 第5.6条 |

## Certificate administration

| Item | Rule | Source |
| --- | --- | --- |
| 更换 | 再次签发记录已填满；证件破损或丢失 | P1 第4.3条(1) |
| 重新颁发 | 适航证被吊销；系统型别发生变化 | P1 第4.3条(2) |
| 转让性 | 适航证可随无人机系统一起转让 | P1 第4.4条 |
| 有效期 | 在中国注册登记期间，按规定维修并按运行限制运行时长期有效 | P1 第4.4条 |
| 存档 | 申请书、检查记录、适航证复印件保存至航空器注销后 2 年 | P1 第4.5条 |
