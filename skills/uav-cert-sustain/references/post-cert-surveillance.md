# Post-certificate changes, surveillance and reporting

依据 P2 第6章至第8章、P3 第3.4节至第5.3节、P4 第4章至第5章、L2 第92.311条。

## Design changes

| Change | Approval route | Source |
| --- | --- | --- |
| 设计小改 | 由设计机构按 DOA 权限批准，并按与 DPI 或项目工程师约定的方式报备 | P2 第8.3条; P3 第7.1条(3) |
| 超出 DOA 权限的小改 | 由局方项目工程师用型号资料批准表批准 | P2 第8.3条 |
| 大改，导致型号合格证或数据单更改 | 提交型号合格证更改申请，按 P2 第3章适用步骤审定 | P2 第8.4.2条 |
| 大改，不导致证件更改 | 书面申请加说明性证明性资料，审查组审定后用型号资料批准表批准 | P2 第8.4.3条 |
| 需全面实质审查的大改 | 申请新型号合格证 | L2 第92.347条; P2 第8.2条 |
| 修理设计，显著影响重量平衡强度可靠性使用特性或适航性 | 向局方提交批准 | P2 第8.5条(1) |
| 其他修理设计 | 由 DOA 持有人按权限批准，或提交项目工程师批准 | P2 第8.5条(2) |

Classify before acting. 重大更改的自动判定准则，满足其一即适用：未保持原有总体构型或构造原理；
取证时采用的前提条件不再有效。依据 P2 第8.2条。

## Organisation-side changes

| Change | Action | Source |
| --- | --- | --- |
| DOA 证件信息或许可项目单信息更改 | 提交设计机构许可证更改申请书，P3 附表9 | P3 第3.4.1条 |
| 设计保证系统重大更改（组织、职责、程序原则、资源四类情形） | 报告 DPI；经 DPI 认可可先行实施再补措施 | P3 第3.4.2条 |
| 其他不影响证件的体系更改 | 按 DPI 同意的方式自行管理，在计划性监督中报告 | P3 第3.4.2条 |
| POA 证书信息更改 | 提交生产机构许可证更改申请书，P4 附表11 | P4 第4.1条 |
| 生产质量系统重要更改 | PI 审查，纠正措施验证完成后以审定信函批准 | P4 第4.4.1条 |
| 许可项目单增项或减项 | 增项由审查组审查，涉及型号时先报审定项目监督管理委员会；减项由 PI 核实 | P4 第4.1.2条 |

## Surveillance

| Activity | Frequency | Source |
| --- | --- | --- |
| DOA 计划性监督 | 至少以 24 个月为 1 个周期，覆盖符合性检查单全部检查项 | P3 第4.2条 |
| DOA 年度监督计划 | 每年 11 月 30 日前编制下一年度计划 | P3 第4.2条 |
| DOA 非计划性监督 | 蓄意违规、批准的设计出现重大问题、严重偏离体系、拒不整改等 | P3 第4.3条 |
| POA 日常监督 | 活跃状态下每 2 年至少一次，含生产质量系统复查、供应商控制审查、主管监察员审查 | P4 第4.3条 |
| POA 随机监督 | 重要更改审查、质量问题调查、非计划审查 | P4 第4.4条 |
| 供应商控制审查通知 | 局方提前 20 天通知 POAH，由 POAH 通知被审查供应商 | P4 第5.2.3条 |

监督延伸到供应商时，DOA 持有人应参加相关审查活动，依据 P3 第5.2条。

## Reporting duties

| Report | Deadline | Source |
| --- | --- | --- |
| 故障、失效、缺陷报告 | 确认后 48 小时内，含周末和节假日 | L2 第92.311条(d); P4 第19节 1901 |
| 设计缺陷调查结果与纠正措施 | 调查表明存在不安全状况时 | L2 第92.311条(e) |
| 生产质量系统重要更改 | 更改发生时 | P4 第4.4.1条 |
| 生产状态转非活跃 | 由活跃转非活跃时书面报告 PI | P4 第4.3.1条 |
| 事件信息 | 按事件信息管理办法报告 | P6 |

须报告的 13 类情形见 P4 第19节 1901，涵盖着火、发动机排气系统故障、有毒有害气体、
螺旋桨操纵系统故障、桨叶结构损坏、易燃液体渗漏、刹车系统失效、主要结构严重缺陷、
异常振动、发动机失效、降低飞行品质的操纵系统故障、发电或液压系统完全失效、
空速姿态高度仪表故障。

## Certificate validity

| Item | Rule | Source |
| --- | --- | --- |
| DOA | 2 年内有效；届满前至少 3 个月申请延续；失效后再申请视为初次申请 | P3 第3.5条 |
| POA | 长期有效，但须持续符合适用要求、接受检查、有效控制生产、未放弃、设计批准有效 | P4 第3.6条 |
| 适航证 | 随系统转让；按规定维修并按运行限制运行时长期有效 | P1 第4.4条 |

## Records

| Record | Retention | Source |
| --- | --- | --- |
| DOA 审查与监督记录 | 不少于 7 个日历年 | P3 第6条 |
| POA 审查与监督管理记录 | 不少于 15 个日历年 | P4 第5.6条 |
| 型号资料（设计数据、图纸、规范、试验大纲与报告、手册、服务通告） | 保存至所有受影响航空器永久退役 | P2 第6.6.2条 |
| 适航证申请书、检查记录、证件复印件 | 至航空器注销后 2 年 | P1 第4.5条 |
