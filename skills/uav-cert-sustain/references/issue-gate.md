# The issue gate

Run this as a written check before submitting anything for TC, DOA or POA issue.
Each line is a question with a verifiable answer, not an opinion.

## TC（型号合格证）颁证前置

依据 P2 第3.10条 与 P2 第3.11条。

| # | Check | Evidence |
| --- | --- | --- |
| 1 | 所有型号资料已获审查认可或批准，纠正措施已落实 | 型号资料批准表清单 |
| 2 | 符合性检查清单覆盖全部适用条款且均满足 | 逐条清单，无空处置 |
| 3 | 所有问题纪要均已关闭 | 问题纪要台账，状态列全为关闭 |
| 4 | 已提交符合性声明 | P2 附表15，表-21-160 |
| 5 | 型号合格证数据单草案已完成 | P2 附表16，表-21-115 |
| 6 | 型号检查报告已完成或飞行试验部分已排入颁证后 3 个月计划 | P2 第3.13条 |
| 7 | 已取得相应设计机构许可证 DOA | DOA 证件或审查结论 |
| 8 | 持续适航文件与飞行手册已批准，或已提交完成计划 | P2 第3.9.14条、P2 第3.9.16条 |

颁证时限：局方自受理申请之日起 20 个工作日内作出决定，依据 L2 第92.305条(a)(5)。
申请书有效期为 3 年，运输类 5 年，依据 L2 第92.329条(b) 与 P2 第6.2条。

## 提交前最后一项：自我复核

Run the phase-① verifiers over the whole submission set, then answer:

| Question | Why it is asked |
| --- | --- |
| 每一份文件的每个条款引用都能在语料中核到吗 | 引错条款是最伤信任的错误 |
| 各份文件对同一时限、同一数值的写法一致吗 | 自相矛盾的材料必然进入第二轮审查 |
| 有没有把局方的动作写成我们的交付物 | 会被要求重写 |
| 有没有把未完成的工作写成已完成 | 一旦被发现，影响远超该条本身 |
| 待确认项是否都显式列出并说明影响 | 空着的未知项会被当成遗漏 |
